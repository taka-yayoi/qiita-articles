[Connect to Databricks from Microsoft Excel \| Databricks on AWS](https://docs.databricks.com/integrations/excel.html) [2023/6/1]の翻訳です。

:::note warn
本書は抄訳であり内容の正確性を保証するものではありません。正確な内容に関しては原文を参照ください。
:::

本書では、Microsoft ExcelからDatabricksに接続するためにどのようにDatabricks ODBCドライバーを使用するのかを説明します。接続を確立すると、ExcelからDatabricksのデータにアクセスできるようになります。また、さらにデータを分析するためにExcelを活用することができます。

# 準備

- [ワークスペースを作成します](https://docs.databricks.com/administration-guide/workspace/index.html#create-a-workspace)。
- Databricksクラスターを作成し、クラスターを用いて関連データを作成します。[Databricksで初めてのETLワークロードを実行する](https://qiita.com/taka_yayoi/items/e27fd8b44308ea4ec8d8)をご覧ください。
- [お使いのOSの64-bitバージョンのODBCドライバーをダウンロードします](https://docs.databricks.com/integrations/jdbc-odbc-bi.html#download-the-odbc-driver)。
- ODBCドライバーをインストール、設定します([Windows](https://docs.databricks.com/integrations/jdbc-odbc-bi.html#odbc-windows) | [MacOS](https://docs.databricks.com/integrations/jdbc-odbc-bi.html#odbc-mac) | [Linux](https://docs.databricks.com/integrations/jdbc-odbc-bi.html#odbc-linux))。このセットアップでは、DatabricksとMicrosoft Excelを接続するために使用するデータソース名(DSN)のセットアップを行います。
- [トークン管理API](https://docs.databricks.com/api/workspace/tokenmanagement)。
- Microsoft Excelのインストール。[トライアルバージョンを使用](https://products.office.com/excel)することもできます。

# Microsoft Excelから接続するステップ

このセクションでは、準備ステップで作成したDSNを用いて、どのようにDatabricksからMicrosoft Excelにデータを取り出すのかを説明します。

:::note info
**注意**
このセクションのステップは、Excel for Microsoft 365 for Mac version 16.70を用いてテストされました。
:::

1. Microsoft Excelで空のワークブックを開きます。
1. **Data**リボンで、**Get Data (Power Query)** の隣の下向きキャレットをクリックし、**From database (Microsoft Query)** をクリックします。
1. **ODBC Data Source Chooser**で、準備ステップで作成したDSNを選択し、**OK**をクリックします。
1. **Username**には`token`を入力します。
1. **Password**では、準備ステップで取得したパーソナルアクセストークンを入力します。
1. **Microsoft Query**ダイアログでは、ExcelにロードしたいDatabricksのテーブルを選択し、**Return Data**をクリックします。
1. **Import Data**ダイアログでは、**Table**と**Existing sheet**を選択し、**Import**をクリックします。

Excelワークブックにデータをロードした後は、そのデータに対する分析オペレーションを実行することができます。
