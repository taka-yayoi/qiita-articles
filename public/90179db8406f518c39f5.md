> サンキーの可視化: サンキーの可視化が AI/BI ダッシュボードで利用できるようになりました。[サンキーダイアグラム](https://docs.databricks.com/aws/ja/dashboards/visualizations/types#sankey)を参照してください。

工程などのステージ間の流量把握が容易に行えます。

https://ja.wikipedia.org/wiki/%E3%82%B5%E3%83%B3%E3%82%AD%E3%83%BC%E3%83%BB%E3%83%80%E3%82%A4%E3%82%A2%E3%82%B0%E3%83%A9%E3%83%A0

データを準備します。

```sql
SELECT pickup_zip as stage1, dropoff_zip as stage2, sum(fare_amount) as value
FROM samples.nyctaxi.trips
GROUP BY 1, 2
ORDER BY 3 DESC
LIMIT 10
```
