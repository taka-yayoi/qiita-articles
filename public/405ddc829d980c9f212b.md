Databricksランタイム14.1でサポートされていたとは。

https://learn.microsoft.com/ja-jp/azure/databricks/sql/language-manual/sql-ref-variables

以前は`spark.conf`を使ってました。上の機能を使うとSQLだけで完結できます。

https://qiita.com/taka_yayoi/items/e447ba254a19bcd8b648

文字列の変数`username`を宣言して、自分のユーザー名を文字列置換したものを変数に設定しています。

```sql:SQL
-- 変数を宣言
DECLARE OR REPLACE username STRING;
-- ユーザー名からピリオド、@を除外
SET VAR username = (SELECT regexp_replace(current_user(), "(\\.|@)", "_"));
```

`SELECT`でアクセスできます。

```sql:SQL
SELECT username;
```

![Screenshot 2024-01-18 at 17.32.48.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1168882/31e02f35-5fdb-9224-bdee-746d9888bd44.png)

[`IDENTIFIER`句](https://learn.microsoft.com/ja-jp/azure/databricks/sql/language-manual/sql-ref-names-identifier-clause)を用いることで、データベース、テーブル名に文字列変数を指定できます。

```sql:SQL
--- quick_start カタログに新規スキーマを作成
CREATE SCHEMA IF NOT EXISTS IDENTIFIER(username)
COMMENT "自分用のUnity Catalogスキーマ(データベース)";
```

変数を用いてデータベースを作成することができました！
