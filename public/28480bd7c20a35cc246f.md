https://qiita.com/isanakamishiro2/items/d095900e7a816a29011c

ちなみに、現時点での正式名称は**Mosaic AI Vector Search**となっています。LLM/RAG関連の機能はすべてMosaic AIの枠組みの中に位置付けられるようになっています。

こちらで構築したVector Indexに対して試してみます。

https://qiita.com/taka_yayoi/items/f174599e4721e51e9e1d

ライブラリ`databricks-vectorsearch`をアップグレードします。そうしないと、ハイブリッド検索の引数を受け付けてくれません。`0.38`になっていることを確認します。

```py
%pip install --upgrade databricks-vectorsearch
dbutils.library.restartPython()
```
![Screenshot 2024-06-10 at 16.40.32.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1168882/11726103-9d06-2967-6a1a-73d286e37df7.png)

Vector Search Indexを取得します。

```py
from databricks.vector_search.client import VectorSearchClient
import os

VECTOR_SEARCH_ENDPOINT_NAME="one-env-shared-endpoint-8"
catalog = "takaakiyayoi_catalog"
dbName = db = "rag_chatbot"

index_name=f"{catalog}.{db}.databricks_documentation_vs_index"
host = "https://" + spark.conf.get("spark.databricks.workspaceUrl")
os.environ['DATABRICKS_TOKEN'] = dbutils.secrets.get("demo-token-takaaki.yayoi", "rag_sp_token")
os.environ["DATABRICKS_HOST"] = host

# vector search indexの取得
vsc = VectorSearchClient(workspace_url=host, personal_access_token=os.environ["DATABRICKS_TOKEN"])
vs_index = vsc.get_index(
    endpoint_name=VECTOR_SEARCH_ENDPOINT_NAME,
    index_name=index_name
)
```

デフォルトの挙動で確認します。[こちら](https://docs.databricks.com/ja/generative-ai/create-query-vector-search.html#query-a-vector-search-endpoint)にあるように、デフォルトは`"ann"`(近似最近傍:approximate nearest neighbor)となっています。

```py
question = "Deltaログの保持期間は？"

results = vsc.get_index(VECTOR_SEARCH_ENDPOINT_NAME, index_name).similarity_search(
  query_text=question,
  columns=["url", "content"],
  num_results=5,
  query_type="ann")
docs = results.get('result', {}).get('data_array', [])
display(docs)
```

ふーんという感じです。

ハイブリッド検索をオンにします。

```py
results = vsc.get_index(VECTOR_SEARCH_ENDPOINT_NAME, index_name).similarity_search(
  query_text=question,
  columns=["url", "content"],
  num_results=5,
  query_type="hybrid")
docs = results.get('result', {}).get('data_array', [])
display(docs)
```
