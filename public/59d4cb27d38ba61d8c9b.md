宣言型ETLを活用して信頼性が高く、運用が容易なデータパイプラインを構築できる[Delta Live Tables(DLT)](https://qiita.com/taka_yayoi/items/7fe8ed2c2f95fd53cc3d)ですが、実際の運用で活用しようとすると色々な悩みに直面するかと思います。

例えば、複雑な処理を必要とするデータパイプラインを構築したい、データソースへのアクセスロジックを共通化したいというケースでは、ソースコードのモジュール化が重要となります。

しかしながら、DLTでソースコードのモジュール化をするには若干工夫が必要となります。

現時点では以下のアプローチがあります。

1. **[Repos](https://qiita.com/taka_yayoi/items/b89f199ff0d3a4c16140)**の**[Files in Repos](https://qiita.com/taka_yayoi/items/b89f199ff0d3a4c16140#pythonr%E3%83%A2%E3%82%B8%E3%83%A5%E3%83%BC%E3%83%AB%E3%81%AE%E3%82%A4%E3%83%B3%E3%83%9D%E3%83%BC%E3%83%88)**機能を用いて、pyファイルをimportする。
2. DLTパイプラインを定義するノートブックを[複数に分割](https://qiita.com/taka_yayoi/items/834b56b30849d63b52d0#%E3%83%91%E3%82%A4%E3%83%97%E3%83%A9%E3%82%A4%E3%83%B3%E3%81%AE%E8%A4%87%E6%95%B0%E3%81%AE%E3%83%8E%E3%83%BC%E3%83%88%E3%83%96%E3%83%83%E3%82%AF%E3%81%AE%E8%A8%AD%E5%AE%9A)する。
3. Sparkの[UDF(ユーザー定義関数)](https://qiita.com/taka_yayoi/items/123347aa8323b4a90730)としてロジックを定義する。

1の方法は以下の記事でも説明されていますが、本記事ではDLTの文脈での利用方法を説明します。

https://qiita.com/maroon-db/items/7b06db3af52796033a06

# 準備

Admin ConsoleでRepos配下の**Files in Repos**を[有効化](https://qiita.com/taka_yayoi/items/b89f199ff0d3a4c16140#files-in-repos%E3%81%AE%E6%9C%89%E5%8A%B9%E5%8C%96)します。
![Screen Shot 2022-02-09 at 10.26.35.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1168882/b6db0905-bbd0-f515-db9e-4757762f8155.png)

Databricksのサイドバーから**Repos**にアクセスして、[リポジトリを作成](https://qiita.com/taka_yayoi/items/b89f199ff0d3a4c16140#%E3%83%AA%E3%83%A2%E3%83%BC%E3%83%88git%E3%83%AA%E3%83%9D%E3%82%B8%E3%83%88%E3%83%AA%E3%81%AE%E3%82%AF%E3%83%AD%E3%83%BC%E3%83%B3)しておきます。

# ロジックの定義

1. Databricksのサイドバーから**Repos**にアクセスします。
1. 上で作成したリポジトリにアクセスします。ここでは`project-test`というリポジトリとします。
1. ロジックを記述するpyファイルを[作成](https://qiita.com/taka_yayoi/items/b89f199ff0d3a4c16140#%E6%96%B0%E8%A6%8F%E3%83%95%E3%82%A1%E3%82%A4%E3%83%AB%E3%81%AE%E4%BD%9C%E6%88%90)します。
1. 作成したいフォルダの右にある下向き矢印をクリックし、メニューから**Create > File**を選択します。
1. ここではファイル名を`func.py`とします。
1. シンプルなロジックを記述しています。

    ```py:Python
def test():
  print("test")
    ```
![Screen Shot 2022-02-09 at 10.39.58.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1168882/cb69fa64-33ef-559e-1e0c-2475c09ac5df.png)

# DLTパイプラインの定義

1. DLTパイプラインを定義するノートブックを作成しオープンします。
1. Reposへのパスを追加します。

    ```py:Python
import sys
sys.path.append("/Workspace/Repos/takaaki.yayoi@databricks.com/project-test")
    ```

    カスタムモジュールをimportします。

    ```py:Python
import func
    ```

1. パイプラインのロジックから`.py`ファイルの関数を呼び出します。

```py:Python
json_path = "/databricks-datasets/wikipedia-datasets/data-001/clickstream/raw-uncompressed-json/2015_2_clickstream.json"

@dlt.table(
  comment="関数呼び出し元テーブル"
)

def caller():
  func.test()
  return (spark.read.json(json_path))
```
