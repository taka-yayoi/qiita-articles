LLMの進化がすごいです。

https://llama.meta.com/llama3/

こちらからモデルへのアクセスを申請します。氏名、誕生日、国、所属などを入力します。

https://huggingface.co/meta-llama/Meta-Llama-3-8B

審査が通ると以下のようなメールが届きます。数分でメールが届きました。
![Screenshot 2024-04-19 at 8.18.10.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1168882/35b02059-6e22-1eda-48f9-2e7588964db3.png)

アクセスが許可されています。
![Screenshot 2024-04-19 at 8.18.31.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1168882/0220a91d-4f17-4c12-853a-7b991234bfef.png)

GPUクラスターを準備します。
![Screenshot 2024-04-19 at 8.33.05.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1168882/5c25dfb0-9cb5-2fd2-d82d-d908236b5840.png)

アクセストークンを用いてHugging Face Hubにログインします。

```py
from huggingface_hub import login
login()
```

サンプルコードを実行します。

```py
import transformers
import torch

model_id = "meta-llama/Meta-Llama-3-8B"

pipeline = transformers.pipeline( "text-generation", model=model_id, model_kwargs={"torch_dtype": torch.bfloat16}, device_map="auto")
pipeline("Hey how are you doing today?")
```

動きました！

```
[{'generated_text': 'Hey how are you doing today? I am doing well. I am a little bit tired because I'}]
```

あとで、日本語や`Meta-Llama-3-8B-Instruct`も試します。色々工夫が必要らしいです。

https://huggingface.co/meta-llama/Meta-Llama-3-8B-Instruct

そして、こちらのブログにあるように、DatabricksはMetaとのパートナーシップを結び、Databricksの[基盤モデルAPI](https://docs.databricks.com/ja/machine-learning/foundation-models/index.html)を通じてLlama3を提供する予定です！

https://www.databricks.com/blog/building-enterprise-genai-apps-meta-llama-3-databricks

こちらの機能も利用できるようになったら試してみます。
