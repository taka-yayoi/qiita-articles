こちらで触れたワークスペースファイル、便利な機能ですが、セキュリティ要件によってはオフにしたいというニーズもあるかと思います。

https://qiita.com/taka_yayoi/items/d61a77747ec7325d6526

こちらのドキュメントには`管理者が REST API を使用して無効にすることができます。`との記載があります。

https://docs.databricks.com/ja/files/workspace.html

しかし、具体的な方法が記載されておらず右往左往しました。

ヒントはこちらにありました。

https://docs.databricks.com/ja/repos/enable-disable-repos-with-api.html

こちらのノートブックを修正して実行することで、ワークスペースファイルを有効・無効にすることができます。ドキュメントチームにはフィードバックしておきます。

デフォルトではワークスペースファイルは有効化されているので、以下のように`py`ファイルなどを作成することができます。

# ワークスペースファイルの無効化

databricks-sdkを使いますが、REST API呼び出しでもいけるはずです。

```py
%pip install databricks-sdk --upgrade
dbutils.library.restartPython()
```

APIクライアントを初期化します。

```py
from databricks.sdk.core import ApiClient

client = ApiClient()
```

キー`enableWorkspaceFilesystem`を指定して、現在の設定を確認します。

```py
client.do("GET", "/api/2.0/workspace-conf", {"keys": "enableWorkspaceFilesystem"})
```

有効化されています。
```json
{'enableWorkspaceFilesystem': 'true'}
```

無効化します。

```py
client.do("PATCH", "/api/2.0/workspace-conf", body={"enableWorkspaceFilesystem": "false"}, headers={"Content-Type": "application/json"})
```

```json
{}
```

設定を反映させるために、ブラウザをリロードします。

メニューから**ファイル**が表示されなくなります。
![Screenshot 2023-11-01 at 16.11.12.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1168882/f4109742-8dbb-c0b9-391b-a7d0ec6b9c6c.png)

# ワークスペースファイルの有効化

再度有効化する際には、キー`enableWorkspaceFilesystem`を`true`に設定します。

```py
client.do("PATCH", "/api/2.0/workspace-conf", body={"enableWorkspaceFilesystem": "true"}, headers={"Content-Type": "application/json"})
```
