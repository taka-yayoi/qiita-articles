深度情報を維持して画像を生成できるんですね。

https://huggingface.co/docs/diffusers/en/using-diffusers/depth2img

> [StableDiffusionDepth2ImgPipeline](https://huggingface.co/docs/diffusers/v0.31.0/en/api/pipelines/stable_diffusion/depth2img#diffusers.StableDiffusionDepth2ImgPipeline)によって、新規画像生成に条件を加えるためにテキストのプロンプトと初期画像を入力する事ができます。さらに、画像の構造を保持するための`depth_map`を指定する事ができます。`depth_map`が指定されない場合、今パイプラインは、インテグレーションされている[depth\-estimation model](https://github.com/isl-org/MiDaS)を通じて、自動で深度を予測します。

[StableDiffusionDepth2ImgPipeline](https://huggingface.co/docs/diffusers/v0.31.0/en/api/pipelines/stable_diffusion/depth2img#diffusers.StableDiffusionDepth2ImgPipeline)のインスタンスを作成します。

```py
import torch
from diffusers import StableDiffusionDepth2ImgPipeline
from diffusers.utils import load_image, make_image_grid

pipeline = StableDiffusionDepth2ImgPipeline.from_pretrained(
    "stabilityai/stable-diffusion-2-depth",
    torch_dtype=torch.float16,
    use_safetensors=True,
).to("cuda")
```

これで、パイプラインにプロンプトを入力できるようになりました。特定の用語が画像生成をガイドしないように、`negative_prompt`を指定することもできます:

```py
url = "http://images.cocodataset.org/val2017/000000039769.jpg"
init_image = load_image(url)
prompt = "two tigers"
negative_prompt = "bad, deformed, ugly, bad anatomy"
image = pipeline(prompt=prompt, image=init_image, negative_prompt=negative_prompt, strength=0.7).images[0]
make_image_grid([init_image, image], rows=1, cols=2)
```

左がオリジナル、右が生成結果。

![download.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1168882/5520af5f-a384-d4ad-3f30-97cbbe8cf42f.png)

プロンプトを変えてみます。

```py
prompt = "two dogs"
negative_prompt = "bad, deformed, ugly, bad anatomy"
image = pipeline(prompt=prompt, image=init_image, negative_prompt=negative_prompt, strength=0.7).images[0]
make_image_grid([init_image, image], rows=1, cols=2)
```

![download (1).png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1168882/ca8f0492-bf73-1891-4860-cbd21e11e17a.png)

パラメーターやネガティブプロンプトも調整してみます。

```py
prompt = "two dogs, cartoon"
negative_prompt = "bad, deformed, ugly, bad anatomy, realistic"
image = pipeline(prompt=prompt, image=init_image, negative_prompt=negative_prompt, strength=1.0).images[0]
make_image_grid([init_image, image], rows=1, cols=2)
```
