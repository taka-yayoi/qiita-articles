# ステップ1: 変数を定義し、 CSVファイルを読み込む

Unity Catalogの[ボリューム](https://docs.databricks.com/ja/connect/unity-catalog/volumes.html)にCSVファイルを格納します。

```py
catalog = "takaakiyayoi_catalog"
schema = "default"
volume = "data"
download_url = "https://health.data.ny.gov/api/views/jxy9-yhdk/rows.csv"
file_name = "rows.csv"
table_name = "health_data"
path_volume = "/Volumes/" + catalog + "/" + schema + "/" + volume
path_tables = catalog + "." + schema
print(path_tables) # 完全パスを表示
print(path_volume) # 完全パスを表示
```
```

/Volumes/takaakiyayoi_catalog/default/data
```

## DataFrame内の行をフィルタリングする

`filter`を用いて**Count**列の値が50よりも大きいものにフィルタリングします。

```py
display(df.filter(df["Count"] > 50))
```

## DataFrame から列を選択し、頻度順に並べ替える

`desc`で**Count**の降順、`orderBy`でソートを支持します。`select`はSQLと同じように列を選択しています。考え方自体、SQLと似ています。

```py
from pyspark.sql.functions import desc
display(df.select("First_Name", "Count").orderBy(desc("Count")))
```
![Screenshot 2024-04-28 at 18.23.47.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1168882/98b08a57-d7a0-61bc-12ef-d798a43a5416.png)

## DataFrameのサブセットを作成する

`filter`で以下の条件を**AND**で指定しています。

- **Year**が`2009`
- **Count**が`100`より大きい
- **Sex**が`F`
- 列は**First_Name**、**County**、**Count**を選択
- **Count**の降順でソート

```py
subsetDF = (
    df.filter((df["Year"] == 2009) & (df["Count"] > 100) & (df["Sex"] == "F"))
    .select("First_Name", "County", "Count")
    .orderBy(desc("Count"))
)
display(subsetDF)
```

## SQLクエリとして列を指定する

selectExprやexprを用いることで、PySparkの中でSQLエクスプレッションを活用することができます。

```py
display(df.selectExpr("Count", "upper(County) as big_name"))
```
![Screenshot 2024-04-28 at 18.29.18.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1168882/8a65458e-fe97-9a5f-656a-ceac938ef2e5.png)

```py
from pyspark.sql.functions import expr
display(df.select("Count", expr("lower(County) as little_name")))
```

## spark.sql() を使用して任意の SQL クエリを 実行する

`spark.sql()`の引数にはSQL文を文字列として指定できます。Pythonの中でクイックにSQLを使いたい際には便利です。

```py
display(spark.sql(f"SELECT * FROM {path_tables}" + "." + f"{table_name}"))
```
