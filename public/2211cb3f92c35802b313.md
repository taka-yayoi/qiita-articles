結構、需要予測のデモをするのですが、きちんと需要予測が何であるのかを顧みずにデモしていることに(今更)気づきました。

# 需要予測とは

例によってGPT-3.5に聞いてみます。

**質問**

> 需要予測を簡単に教えてください

**回答**

> 需要予測は、将来の商品やサービスの需要を予測することです。ビジネスや組織が効率的な在庫管理や生産計画を立てるために重要です。以下に簡単な需要予測の手順を示します：
> 
> 1. **データ収集**: 過去の売上データや需要データを収集します。このデータは、商品やサービスの販売数量や需要量、時期ごとのパターンなどを含みます。
> 
> 2. **データの分析**: 収集したデータを分析し、トレンドや季節性、特定の影響因子（例えばマーケティングキャンペーン、経済指標の変化など）を特定します。これにより、将来の需要に影響を与える要因を理解します。
> 
> 3. **予測モデルの選択**: 分析結果を基に、適切な予測モデルを選択します。代表的なモデルには、移動平均法、時系列分析（ARIMAモデル）、機械学習モデル（ランダムフォレスト、ニューラルネットワークなど）があります。
> 
> 4. **モデルの構築**: 選択したモデルを使って、将来の需要を予測します。モデルの構築には、データのトレーニング（過去のデータを使ってモデルを学習させる）とテスト（予測精度を評価する）が含まれます。
> 
> 5. **予測の精度評価**: 予測結果の精度を評価し、必要に応じてモデルを調整します。これにより、より正確な予測結果を得ることができます。
> 
> 6. **予測結果の活用**: 最終的な予測結果を基に、在庫管理や生産計画、マーケティング戦略などの意思決定を行います。

## 移動平均による需要予測

予測手法にはいろいろありますが、ここでは[こちら](https://qiita.com/hasegawa16777216/items/31ebbeb2854e5c2a1867)で説明されている移動平均を使います。過去の平均を未来の予測に使ったろアプローチなので、毎年の傾向が類似している場合にはうまくいきますが、コロナのような突発的な事象には弱いですね。[そのようなケースに対応するための手法](https://qiita.com/taka_yayoi/items/810921ee3b30610ee521)も開発されているのがすごいところ。

2022年のデータから移動平均を計算します。

```py
# 2022年のデータをフィルタリング
small_df_2022 = df[df["date"].dt.year == 2022]

# 前3ヶ月の移動平均を計算し、新しい列として追加
small_df_2022["rolling_mean_3"] = (
    small_df_2022["monthly_sales"].rolling(window=3).mean()
)

# 生データと移動平均のデータを可視化
plt.plot(
    small_df_2022["date"], small_df_2022["monthly_sales"], color="red", label="raw_data"
)
plt.plot(
    small_df_2022["date"],
    small_df_2022["rolling_mean_3"],
    color="blue",
    label="rolling_mean",
)
plt.ylabel("monthly_sales")  # y軸のラベル
plt.xlabel("date")  # x軸のラベル
plt.legend(loc="upper right")  # 凡例の位置
plt.show()  # グラフを表示
```

![download (1).png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1168882/4889f082-e9fa-4aed-4516-aeb323c39d05.png)

2022年の移動平均と2023年の実績を比較します。

```py
# 2022年と2023年に絞る
small_df_2022 = df[df["date"].dt.year == 2022]
small_df_2023 = df[df["date"].dt.year == 2023]

# 月の列の追加
months = [i for i in range(1, 13)]
small_df_2022["months"] = months
small_df_2023["months"] = months
# 移動平均を計算・列に追加
small_df_2022["rolling_mean_3"] = (
    small_df_2022["monthly_sales"].rolling(window=3).mean()
)
small_df_2023["rolling_mean_3"] = (
    small_df_2023["monthly_sales"].rolling(window=3).mean()
)
# 可視化
plt.plot(
    small_df_2023["months"],
    small_df_2023["monthly_sales"],
    color="red",
    label="2023_raw",
)
plt.plot(
    small_df_2022["months"],
    small_df_2022["rolling_mean_3"],
    color="blue",
    label="2022_rolling",
)
plt.ylabel("monthly_sales")
plt.xlabel("month")
plt.legend(loc="upper right")
plt.show()

# MAEで精度の確認
small_df = small_df_2022.dropna()  # window=3の移動平均なので最初２つの行はNaNになっている
from sklearn.metrics import mean_absolute_error

print(
    mean_absolute_error(small_df_2023["monthly_sales"][2:], small_df["rolling_mean_3"])
)
```

## Databricks AutoMLによる需要予測

上のようにノートブックでロジックを組み立てることで需要予測を行うことができますが工数がかかります。[Databricks AutoML](https://docs.databricks.com/ja/machine-learning/automl/index.html)を活用することで、クイックに機械学習モデルを構築し、予測結果を得ることができます。

- **クラスター:** MLクラスターを選択
- **機械学習の問題のタイプ:** 回帰、分類、予測から選択
- **入力学習用データセット:** トレーニングに使用するDeltaテーブルを選択
- 予測の場合
    - **予測ターゲット:** 予測する値を格納する列を選択
    - **時間列:** 日時を格納する列を選択
    - **予測期間と頻度:** どれだけ先の期間を予測するのかを指定
    - **出力用データベース:** 予測結果テーブルを格納するデータベースを指定
