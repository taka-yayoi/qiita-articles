[Cursor](https://www.cursor.com/ja)良いですよね。そして、[MCP](https://docs.cursor.com/context/model-context-protocol)(Model Context Protocol)も気になっています。

https://zenn.dev/cloud_ace/articles/model-context-protocol

AI界のUSB-Cとな。

しかし、気になっているだけでは理解が進まないので実際に動かしてみようと思いネットを検索したら、すでにDatabricks MCPサーバーがいくつか公開されていました。

https://github.com/JustTryAI/databricks-mcp-server

https://github.com/RafaelCartenet/mcp-databricks-server

2つ目の方をCursorから使えるようにしてみます。

# 事前準備

アクセスするDatabricksワークスペースの以下の情報を収集しておきます。

- Databricksワークスペースのホスト名
- パーソナルアクセストークン
- SQLウェアハウスのID

# MCPサーバーの設定

`uv`がない場合はインストールします。

```sh
# MacOS/Linux
curl -LsSf https://astral.sh/uv/install.sh | sh
```

```sh
git clone https://github.com/RafaelCartenet/mcp-databricks-server.git
cd mcp-databricks-server
uv venv
source .venv/bin/activate
uv pip install -r requirements.txt
```

# Cursorの設定

```sh
touch ~/.cursor/mcp.json
```

Cursorのメニューの**設定 > Cursorの設定 > MCP**で **+ Add new global MCP server** をクリックして、以下のように設定します。私の場合は、`/Users/takaaki.yayoi/Workspace/databricks_mcp/mcp-databricks-server`に上のMCPサーバーを構成しています。

```json
{
    "mcpServers": {
        "databricks": {
            "command": "uv",
            "args": [
                "--directory",
                "/Users/takaaki.yayoi/Workspace/databricks_mcp/mcp-databricks-server",
                "run",
                "main.py"
            ],
            "env": {
                "DATABRICKS_HOST": "https://<Databricksワークスペースのホスト名>.cloud.databricks.com",
                "DATABRICKS_TOKEN": "<パーソナルアクセストークン>",
                "DATABRICKS_SQL_WAREHOUSE_ID": "<SQLウェアハウスID>"
            }
        }
    }
}
```

MCPサーバーが設定されました。
