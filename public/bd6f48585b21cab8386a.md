[Databricksアシスタント](https://docs.databricks.com/ja/notebooks/databricks-assistant-faq.html)が、Databricks内で全てがホスティングされ、管理されるようになったことを発表できて嬉しく思っており、現在はパブリックプレビューとなっています！このバージョンは、アシスタントがDatabricksにホスティングされているモデルのみを利用し、Databricksモデルサービングを支えているのと同じセキュアなインフラストラクチャを活用します。このエンハンスメントによって、すべてのお客様は自身のデータ処理が自分のDatabricksアカウント内に留まるようにしながらも、我々のAIを活用したアシスタントのすべてのメリットを享受できるようになります。

![](https://www.databricks.com/sites/default/files/inline-images/image1_39.png?v=1732221590)

# Databricksアシスタント

[Databricksアシスタント](https://www.databricks.com/jp/product/databricks-assistant)を用いて、我々は企業データに最適なAIを活用した生産性ツールの構築に着手しました。プレビュー依頼の導入度合いは驚くべきものでした。アシスタントは、かつてないほど急速に成長しているDatabricksの機能の一つであり、17万人以上のユーザーが毎週、コードを自動的に生成、修正し、エラーをトラブルシュートし、微ジュアライゼーションやダッシュボードを作成するために、アシスタントを活用しています。

# 主要な機能と能力

このパブリックプレビューは、USとEUリージョンのAWSを利用のお客様にはデフォルトで独占的に、[Databricksアシスタントのクイックフィックス](https://www.databricks.com/jp/blog/introducing-databricks-assistant-quick-fix)で提供されます。プレビューが進むにつれて、Databricksアシスタントのチャットやノートブックのインラインアシスタント、ファイルエディタ、SQLエディタにも展開していきます。

現時点では、このプレビューにはAI/BIダッシュボードとGenieは含まれないことに注意してください。

# モデルとモデルサービング

このプレビューでは、Databricksがホストするモデルと、モデルサービングエンドポイントを活用し、お客様が基盤モデルAPIにクエリーする際に使用しているのと同じ、セキュアで統治されたインフラストラクチャを活用します。アシスタントのローンチ以来、我々はコードのインタラクションのための別のモデルを探索し続けており、すでにAI生成コメントやオートコンプリートのような様々な機能で、Databricksがホストするモデルをデプロイしています。

このプレビューでは、アシスタントは[オープンソースAIの新たなスタンダードを打ち立てた](https://www.databricks.com/jp/blog/new-standard-open-source-ai-meta-llama-31-databricks)MetaのLlama 3を使用しています。我々のユーザーにおける最高のパフォーマンス標準を確実なものにするために、今後出現するモデルを継続的に評価していくことにコミットしています。このアプローチは、スムーズなインテグレーションを保証するだけでなく、レイテンシーを最小化することでスピードを改善します。

# セキュリティとプライバシーの強化

このプレビューでは、Databricksによって完全に管理、保護されているモデルサービングエンドポイントを活用しており、外部モデルプロバイダーへの依存性を排除し、皆様のデータが格納時も利用時もあなたのDatabricksアカウントの中にあり続けるようにします。我々のエンドポイントはステートレスであり、堅牢なセキュリティを確実なものにするために、複数レイヤーの分離によってガードされています。

我々は、最初から企業ワークロードの要件を満たすように、Databricksアシスタントを設計しました。アシスタントは、Unity Catalogのガバナンスに準拠し、高度に規制された業界のコンプライアンス標準を満足します。あなたのデータは決して他のお客様と共有されず、モデルのトレーニングには使用されません。信頼と安全性に対する我々のコミットメントの詳細については、[Databricksの信頼性と安全性に関するドキュメント](https://docs.databricks.com/ja/databricksiq/databricksiq-trust.html)をご覧ください。

# 今後の開発

我々は、partner-powered AIの設定で提供されるのと同等になるまで、追加のアシスタント機能を徐々にロールアウトしていきます。さらに、すべてのクラウドプラットフォームでこのバージョンを使えるようにし、選択されたCompliance Security Profile (CSP)ワークスペースでも有効化します。

# 使い始める

Partner-powered AIの設定を無効化した場合にのみ、アシスタントはDatabricksがホスト、管理するモデルを使用します。Partner-powered AIの設定を有効かしているお客様には影響がありません。USとEUのすべてのAWSワークスペースでは、このパブリックプレビューに自動的に登録され、管理者は必要に応じてプレビューポータルから無効化する事ができます。他のリージョンのAWSのお客様もプレビューポータルから、このパブリックプレビューに参加できますが、このパブリックプレビューではUSとEUリージョンのみでホストされることに注意してください。

Databricksアシスタントの実際を見るためには、我々の[製品ページ](https://www.databricks.com/jp/product/databricks-assistant)をご覧ください。アシスタントはDatabricksインテリジェンスプラットフォームで活用され、皆様のデータが保護され、あなたへのレスポンスが正確で、パーソナライズされるようにします。自然言語であなたのタスクを説明し、アシスタントにSQLクエリーを生成させ、複雑なコードを説明さ性、自動でエラーを修正させましょう。
