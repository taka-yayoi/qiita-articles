久々にTerraformを使おうとしたらこちらでレポートされている事象に。

https://discuss.hashicorp.com/t/terraform-0-13-5-being-flagged-as-malicious-on-macos/53096

バージョンを上げることで解決できました。

tfenvが必要なのでインストールしようとしました。

https://spacelift.io/blog/terraform-version-upgrade

が、エラー。

```
Error: Cannot install tfenv because conflicting formulae are installed.
  terraform: because tfenv symlinks terraform binaries
```

こちらにあるように、先にterraformをunlink

https://kamatimaru.hatenablog.com/entry/2020/05/21/040106

```sh
brew unlink terraform
```

```sh
brew install tfenv
```

```sh
tfenv intall 1.4.6
```

これで動くようになりました！
