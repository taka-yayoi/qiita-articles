:::note info
**注意**

:::


# シークレットの設定

OpenAIのAPIキーを[シークレット](https://docs.databricks.com/ja/security/secrets/secrets.html)に登録する必要があります。

Databricks CLIをインストールしたローカルマシンで以下を実行します。`-p tokyo`はプロファイルを指定しています。

```sh
databricks secrets create-scope demo-token-takaaki.yayoi -p tokyo
```

```sh
databricks secrets put-secret demo-token-takaaki.yayoi openai -p tokyo           
```

プロンプトが表示されるのでAPIキーを入力します。

```
✔ Please enter your secret value:
```

# サービングエンドポイントの作成

サイドメニューの**サービング**にアクセスし、**Create serving endpoint**をクリックします。
![Screenshot 2024-04-08 at 10.48.14.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1168882/d57ec187-f28d-3e85-8089-6592378b7d75.png)

**Source**で**External model**を選択します。
![Screenshot 2024-04-08 at 10.48.25.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1168882/c1bd56de-3a4c-2f9d-2556-974db157cde5.png)

**Provide**で**OpenAI**を選択します。
![Screenshot 2024-04-08 at 10.48.32.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1168882/adcc5bc6-5e36-88a3-dd3a-ccf92132a60f.png)

**External model name**は、[こちら](https://docs.databricks.com/ja/generative-ai/external-models/index.html#supported-models)を参考ください。`gpt-3.5-turbo-instruct`を指定します。
![Screenshot 2024-04-08 at 10.51.17.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1168882/421e480b-abd2-629a-d8d3-92fa7f043bb4.png)

**OpenAI API key secret reference**には`{{secret/scope/key}}`の形式で指定します。今回は`{{secrets/demo-token-takaaki.yayoi/openai}}`となります。

これで、エンドポイントが作成されました。
![Screenshot 2024-04-08 at 10.51.26.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1168882/fa0bcee1-5311-170d-e203-888c3cfbb6ef.png)

右上の**Query endpoint**で動作確認します。
![Screenshot 2024-04-08 at 10.51.26.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1168882/75f7762e-7aac-21ca-4690-0a56ececde14.png)
