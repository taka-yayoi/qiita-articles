# 集計

> 都道府県別、月別の感染者数のデータをください

```sql
SELECT Prefecture, DATE_TRUNC('month', date_timestamp) AS Month, SUM(Cases) AS TotalCases
FROM takaakiyayoi_catalog.japan_covid_analysis.covid_cases
GROUP BY Prefecture, Month
ORDER BY Prefecture, Month
```

# 変動

> 最も感染者数の増加率が高かったのはどの県でいつのことですか

```sql
WITH cases_by_prefecture AS (
  SELECT Prefecture, DATE_TRUNC('month', date_timestamp) AS Month, SUM(Cases) AS TotalCases
  FROM takaakiyayoi_catalog.japan_covid_analysis.covid_cases
  GROUP BY Prefecture, Month
),
cases_growth_rate AS (
  SELECT Prefecture, Month, TotalCases,
         LAG(TotalCases) OVER (PARTITION BY Prefecture ORDER BY Month) AS PreviousCases,
         (TotalCases - LAG(TotalCases) OVER (PARTITION BY Prefecture ORDER BY Month)) / LAG(TotalCases) OVER (PARTITION BY Prefecture ORDER BY Month) AS GrowthRate
  FROM cases_by_prefecture
),
max_growth_rate AS (
  SELECT Prefecture, Month, GrowthRate
  FROM cases_growth_rate
  WHERE GrowthRate = (SELECT MAX(GrowthRate) FROM cases_growth_rate)
)
SELECT Prefecture, Month
FROM max_growth_rate
```

これはすごい。キチンとLAG関数使って前月からの変動率を計算している。
