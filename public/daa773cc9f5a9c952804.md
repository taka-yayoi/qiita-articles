# DATA + AI SUMMIT KEYNOTE, WEDNESDAY

https://www.databricks.com/dataaisummit/session/data-ai-summit-keynote-wednesday

**水曜日のキーノート**

データとAUの正解に向けては複雑性が長い間障壁であり続けていました。しかし、生成AIとレイクハウスアーキテクチャの統合は、シンプルさに対する新たな機械への扉を急激に開きつつあります。あなたのデータにAIを持ちこむことで、効率性を改善し、創造的思考を刺激し、生産性を向上するアウトプットを生成するために、様々なソースからの膨大な量の情報を分析できる様になります。

DatabricksのデータインテリジェンスプラットフォームにおけるAI、データウェアハウス、分析の最新のイノベーションに関してDatabricks創業者からの話を聞きましょう。さらに、AIの大家やデータリーダーが、データとAIの間の相互接続性と、悪いデータから良いモデルを救い出す方法を探索します。

https://www.databricks.com/dataaisummit/session/data-ai-summit-keynote-thursday

**木曜日のキーノート**

さらに、Databricks創業者とプロダクトリーダーが、Unity Catalogを用いてすべてのデータとAIに対する共通的なアプローチを用いて、どのようにデータをセキュアにと打ちて切るのかに関した道筋を図で説明し、取り込みからアプリケーションに至るデータの品質とレスポンシブルなAIの維持を劇的に簡単なものにします。

# DATA WAREHOUSING PERFORMANCE, SCALE AND SECURITY WITH DATABRICKS SQL

https://www.databricks.com/dataaisummit/session/data-warehousing-performance-scale-and-security-databricks-sql

**Databricks SQLによるデータウェアハウスのパフォーマンス、スケール、セキュリティ**

企業やミッションクリティカルな環境でのデータウェアハウスには、コストパフォーマンスやセキュリティに対する格別の検討が必要となります。このセッションでは、Databricks SQLがどのように、高い同時接続性、低レーテンシーのパフォーマンス、ユーザーIDの管理、大規模なアクセスとガバナンスに関する最も困難な要件に取り組んでいるのかを説明します。また、シームレスなパフォーマンスやワークロード管理を実現するリソースベースのスケジュール、オートスケール、キャッシュ強化に関する最新の進歩もカバーします。

# DELTA LAKE UNIFORM: UNIFY TABLE FORMATS ACROSS ICEBERG, HUDI, AND DELTA LAKE

https://www.databricks.com/dataaisummit/session/delta-lake-uniform-unify-table-formats-across-iceberg-hudi-and-delta

**Delta Lake UniForm: Iceburg、Hudi、Delta Lakeのテーブルフォーマットを統合**

Delta Lake Universal Format、縮めてUniFormは、あなたのレイクハウスアーキテクチャにおけるすべてのツールで使用される単一のデータセットを実現することで、Delta Lakeの既存のエコシステムを拡張します。UniFormを用いる小非準拠で、あなたはご自身のデータを一度保存するだけでよく、Linux FoundationのDelta LakeやApache Iceberg、そして間も無くApache Hudiのような主要なオープンテーブルフォーマットを用いるすべてのソフトウェアがアクセスできるようになります。これは、Delta Lakeと共にIcebergやHudiのメタデータを作成することで実現され、背後のParquetデータファイルに対する単一のコピーを維持します。

我々のセッションでは、現時点でUniFormに何ができるのか、今後何ができる様になるのかを説明し、皆様のレイクハウスアーキテクチャにDelta Lake UniFormを追加するベストな方法をカバーします。

# GETTING STARTED WITH DLT PIPELINES

https://www.databricks.com/dataaisummit/session/getting-started-dlt-pipelines

**DLTパイプラインを使い始める**

Delta Live Tables (DLT)は、データチームがストリーミングやバッチETLをコスト効率よくシンプルにする助けとなるDatabricksデータインテリジェンスプラットフォームのデータパイプラインフレームワークであり、タスクのオーケストレーション、クラスター管理、監視、データ品質、エラー対応を自動化します。

DLTを使い始めるのがどれだけ簡単であるのかを体験するためにこのセッションに参加してください！バッチパイプラインやストリーミングパイプライン、その両方を取り扱っていたとしても、移行は簡単であり、皆様のチームにおけるオペレーションのオーバーヘッドを劇的にシンプルなものにしつつも、コラボレーションを強化します。パイプラインの作成、オペレーション、移行、最新機能、今後提供される機能をカバーします。

# INTRODUCTION TO MOSAIC AI: HOW DATABRICKS SIMPLIFIES YOUR GENAI JOURNEY

https://www.databricks.com/dataaisummit/session/introduction-mosaic-ai-how-databricks-simplifies-your-genai-journey

**Mosaic AIのご紹介: Databricksがあなたの生成AIジャーニーをどの様にシンプルにするのか**

生成AI(GenAI)アプリケーションの作成と維持管理を円滑にするために設計された、DatabricksによるMosaic AIの機能に飛び込みましょう。この入門セッションでは、Mosaic AIが提供する包括的なツールを通じて、参加者をガイドし、いかなるサイズの組織における生成AI開発プロセスをどの様にシンプルにするのかをデモンストレーションします。また、データインテリジェンスプラットフォームの上でご自身のAI資産を構築することで、どのように皆さのチームがより効果的にし、企業データを容易に統治、保護できる様になるのかをカバーします。

キーとなる持ち帰り事項は以下の通りです:

- 効率的な生成AIアプリケーション開発を促進するMosaic AIの役割の理解
- 生成AIアプリケーションの作成、デプロイ、管理のためのMosaic AIで利用できるツールの探索
- 高品質な生成AIプロジェクトを維持するためのMosaic AI活用のベストプラクティス

# UNIFYING CONTENT AND COMMERCE LIFECYCLE DATA FOR BUSINESS INSIGHTS

https://www.databricks.com/dataaisummit/session/unifying-content-and-commerce-lifecycle-data-business-insights

**ビジネス洞察のためのコンテンツと商取引ライフサイクルの統合**

このセッションでは、革命的なデータ製品であるGraphiteをご紹介します。Graphiteは、コンテンツライフサイクルデータをクエリー、可視化する統合アプリケーションを提供し、アフィリエイトの売り上げやサブスクリプションのような収益ストリームに洞察を提供します。このプレゼンテーションでは、Graphiteの目的、Databricksオンラインテーブルを用いたリアルタイム機能、サーバレスジョブクラスターやSQLウェアハウス、DatabricksIQによる自然言語クエリーの活用、今後の開発予定をカバーします。Databricksのテクノロジーと連携することで、GraphiteはCondé Nastにおいてコンテンツデータとのやり取りに関して革新的なシフトを推進し、Databricksレイクハウスアーキテクチャをベースとした統合データプラットフォーム構築において、自分自身を重要なプレーヤーと位置付けています。

# UNITY CATALOG MIGRATION AND ADOPTION AT SCALE WITH ADIDAS

https://www.databricks.com/dataaisummit/session/unity-catalog-migration-and-adoption-scale-adidas

**アディダスによる大規模なUnity Catalogの移行と導入**

スポーツ用品におけるグローバルリーダーであるアディダスが、Unity Catalogを用いてどのように自身のデータプラットフォーム戦略を革新し、イノベーションを醸成したのかを探索しましょう。データとAIの統合にフォーカスすることで、アディダスは自身のデータ管理プロセスを整流化するジャーニーに旅立ち、データ資産から最大限の価値を導き出せる様にチームを強化しています。このセッションでは以下をカバーします:

- 統合データガバナンス: レイクハウスアーキテクチャにおけるデータガバナンスに対する統合アプローチを確立するためにどのようにUnity Catalog(UC)を活用したのか
- データ資産のカタログ化: Unity Catalogが様々なドメインにまたがる250+のデータ製品をどのようにカタログ化し、整理したのか
- 導入のジャーニー: ベストプラクティス、直面した課題、得られた知見。イノベーションの加速: 様々なペルソナが彼らのデータ資産からアクション可能な洞察を導き出し、コラボレーションするためにどのようにUCが働いたのか
- 将来的なロードマップ: ガバナンスの取り組みを拡大し、出現するテクノロジーを導入する計画

# WHAT’S NEW IN UNITY CATALOG—WITH LIVE DEMOS

https://www.databricks.com/dataaisummit/session/whats-new-unity-catalog-live-demos

**Unity Catalogの新機能とライブデモ**

データとAIのガバナンスにおける詳細な探索のためにUnity Catalogプロダクトチームに会いましょう。Unity Catalogは、DatabricksデータインテリジェンスプラットフォームネイティブのデータとAIに対する統合ガバナンスを提供する唯一のソリューションです。このセッションでは、詳細な行列フィルタリング、ガバナンスタグ、属性ベースのアクセスコントロール(ABAC)のような最新の機能、自動化されたデータリネージ、ML資産のガバナンス、パフォーマンス改善に関する最新のアップデートを詳らかにします。

デモも提供されるこのセッションでは、Unity Catalogの新機能が、皆様のデータガバナンスプロセスをどのようにシンプルにし、分析やAIの取り組みをシンプルにするのかを説明します。我々の将来的な計画に関する他では見ることのできないプレビューを得ることができます。それに加えて、製品エキスパートにあなた自身が聞きたい質問をぶつけ、なぜUnity Catalogが皆様のデータやAIに対するベストなソリューションであるのかを学びましょう。Unity Catalogであなたのデータゲームをレベルアップさせるこの素晴らしい機会を見逃さないでください！

# WHAT'S NEW WITH DATA SHARING AND COLLABORATION

https://www.databricks.com/dataaisummit/session/whats-new-data-sharing-and-collaboration

**データ共有、コラボレーションの新機能**

Databricksはセキュアでオープンなコラボレーションのプラットフォームです。組織ではデータ以上のものをサポートする共有ソリューションを必要としています。イノベーションを加速するために我々は最近、AIモデル共有をリリースし、データとAIのユースケースを解放するための画像、音声、動画などのためのボリューム共有、業界ユースケースに特化したソリューションアクセラレータをリリースしました。

Databricksデータインテリジェンスプラットフォームは、最大のリーチとインパクトをもたらす共有に対するオープンなアプローチを提供します。皆様の組織では、プライバシーが保護されたコラボレーションを提供する膨大なリーチを持つオープンなエコシステムを用いて、シームレスかつ統合された方法でデータセット、AIモデル、ボリュームを共有することができます。

このセッションでは、プラットフォーム横断のデータ共有のためのオープンプロトコルであるDelta Sharing、データとAIソリューションのオープンマーケットプレースであるDatabricksマーケットプレース、プライバシーが保護されたデータとAIのコラボレーション環境であるDatabricksクリーンルームの最新状況をカバーします。盛りだくさんのセッションに参加して、皆様のデータ共有に関する質問をぶつけましょう！
