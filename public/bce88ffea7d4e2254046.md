こちらのアップデートです。

https://docs.databricks.com/en/release-notes/product/2024/february.html#create-tables-from-files-in-volumes

> You can now use the UI to create Unity Catalog managed tables from data files stored in Unity Catalog volumes. See Create table from volumes.

> Unity Catalogボリュームに格納されるデータからUnity Catalogのマネージドのテーブルを作成するためにUIを使うことができます。[ボリュームからのテーブル作成](https://docs.databricks.com/ja/catalog-explorer/manage-volumes.html)をご覧ください。

カタログエクスプローラからボリュームにアクセスして、ファイルのコンテキストメニューを開きます。**テーブルを作成**を選択できるようになっています。
![Screenshot 2024-02-09 at 13.25.08.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1168882/53aae5ef-51fa-4ec5-b393-158c78ef9218.png)

ダイアログが開くのでターゲットのカタログ、スキーマ、テーブル名を指定します。
![Screenshot 2024-02-09 at 13.25.43.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1168882/01f7309f-50fd-bcdd-dcee-190e3fd7e769.png)
![Screenshot 2024-02-09 at 13.26.11.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1168882/c391f143-6686-d390-bfa2-d6d5522a72ae.png)

テーブルが作成されました。お手軽です。
