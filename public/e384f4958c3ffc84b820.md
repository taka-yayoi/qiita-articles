# パスの指定方法

[こちら](https://docs.databricks.com/ja/files/index.html#do-i-need-to-provide-a-uri-scheme-to-access-data)にあるように、パスの指定の方法には二種類あります(これもわかりにくいですが)。

- **URIスタイル** パスの先頭に`dbfs:/`、`file:/`、`s3://`を付けることでアクセス先を切り替えます。

    ![](https://docs.databricks.com/ja/_images/uri-paths-aws.png)

- **POSIXスタイル** ルート`/`からスタートして、トップレベルのパスでアクセス先を切り替えます。

    ![](https://docs.databricks.com/ja/_images/posix-paths.png)

# まとめ

Sparkでワークスペースファイルにアクセスする際には、`file:`を忘れないようにしてください。

|  | ボリューム | ワークスペースファイル | 
|:--|:--|:--|
| Apache Spark  |  `/Volumes/...` |  `file:/Workspace/...` | 
|  Spark SQL | `/Volumes/...`  | `file:/Workspace/...`  | 
| Bashシェル  | `/Volumes/...`  |  `/Workspace/...` |  
| Pandas  |  `/Volumes/...` | `/Workspace/...`  |
