# 別のグラフを描かせる

> 都道府県別の感染者数比率を表す円グラフをプロットしたい

これですと、都道府県名の列が「都道府県」になってしまい、うまくいきませんでした。実際にはPrefectureです。なので、

> 都道府県別の感染者数比率を表す円グラフをプロットしたい。都道府県はPrefecture列に入っています。

```py
import pandas as pd
import matplotlib.pyplot as plt

# テーブルをSparkデータフレームにロード
df = spark.read.table('takaakiyayoi_catalog.japan_covid_analysis.covid_cases')

# データフレームをPandasデータフレームに変換
pandas_df = df.toPandas()

# 都道府県別の感染者数を集計
cases_by_prefecture = pandas_df['Prefecture'].value_counts()

# ラベルとして都道府県を取得
labels = cases_by_prefecture.index.tolist()

# 感染者数の割合を取得
sizes = cases_by_prefecture.values.tolist()

# 円グラフを作成
plt.pie(sizes, labels=labels, autopct='%1.1f%%')
plt.title('都道府県別COVID-19感染者数比率')
plt.axis('equal')  # アスペクト比を揃える
plt.show()
```

いけた！と思ったら`value_count`してる…。
![Screenshot 2024-01-31 at 15.18.31.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1168882/184ca765-292b-486d-2e90-6662d4c16842.png)

> 都道府県別の感染者数比率を表す円グラフをプロットしたい。都道府県はPrefecture列に入っています。感染者数はCasesに入ってます。

```py
import pandas as pd
import matplotlib.pyplot as plt

# テーブルをSparkデータフレームにロード
df = spark.read.table('takaakiyayoi_catalog.japan_covid_analysis.covid_cases')

# データフレームをPandasデータフレームに変換
pandas_df = df.toPandas()

# 都道府県別の感染者数を集計
cases_by_prefecture = pandas_df.groupby('Prefecture')['Cases'].sum()

# ラベルとして都道府県を取得
labels = cases_by_prefecture.index.tolist()

# 感染者数の割合を取得
sizes = cases_by_prefecture.values.tolist()

# 円グラフを作成
plt.pie(sizes, labels=labels, autopct='%1.1f%%')
plt.title('都道府県別COVID-19感染者数比率')
plt.axis('equal')  # アスペクト比を揃える
plt.show()
```

ちなみにplotly使えば文字化けに悩むことなかったですね。

> takaakiyayoi_catalog.japan_covid_analysis.covid_casesをplotlyで可視化したいので、Pythonコードを作成してください。

```py
# 必要なライブラリをインポート
import plotly.express as px
import pandas as pd

# データを読み込み
df = spark.table("takaakiyayoi_catalog.japan_covid_analysis.covid_cases")

# Spark DataFrameからPandas DataFrameに変換
df_pd = df.toPandas()

# Plotlyを使って可視化
fig = px.line(df_pd, x='date_timestamp', y='Cases', color='Prefecture', title='COVID-19 Cases by Prefecture')
fig.show()
```
