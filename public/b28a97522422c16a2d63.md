# データの定義

ここでは、タクシー乗降記録のサンプルデータを使用します。

左上の**データ**タブをクリックします。
![Screenshot 2024-05-02 at 18.05.23.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1168882/3a492108-28fa-e3d1-af57-4e7515fb1b11.png)

**SQLから作成**をクリックします。テーブルのデータをそのまま使用する際には、**テーブルを選択**でも大丈夫です。
![Screenshot 2024-05-02 at 18.05.41.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1168882/bca9cdc5-ef4f-9d8b-7193-b1c6d62e8da9.png)

以下のSQLを貼り付けます。

```sql
SELECT
  T.tpep_pickup_datetime,
  T.tpep_dropoff_datetime,
  T.fare_amount,
  T.pickup_zip,
  T.dropoff_zip,
  T.trip_distance,
  T.weekday,
  CASE
    WHEN T.weekday = 1 THEN 'Sunday'
    WHEN T.weekday = 2 THEN 'Monday'
    WHEN T.weekday = 3 THEN 'Tuesday'
    WHEN T.weekday = 4 THEN 'Wednesday'
    WHEN T.weekday = 5 THEN 'Thursday'
    WHEN T.weekday = 6 THEN 'Friday'
    WHEN T.weekday = 7 THEN 'Saturday'
    ELSE 'N/A'
  END AS day_of_week,
  T.fare_amount,
  T.trip_distance
FROM
  (
    SELECT
      dayofweek(tpep_pickup_datetime) as weekday,
      *
    FROM
      `samples`.`nyctaxi`.`trips`
    WHERE
      trip_distance > 0
      AND trip_distance < 10
      AND fare_amount > 0
      AND fare_amount < 50
  ) T
ORDER BY
  T.weekday
```

クエリーを実行して結果を表示させます。
