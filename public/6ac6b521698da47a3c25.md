こちらを読んで試してみようと思いました。

https://qiita.com/tom_m_m/items/91ba624dd8507bc0b746

マニュアルを読むと`pip install librosa`で行けるようです。

https://librosa.org/doc/latest/index.html

ところが、実際にやってみるとエラーに。

```
%pip install librosa
```

```py:Python
import librosa
```

```
OSError: cannot load library 'libsndfile.so': libsndfile.so: cannot open shared object file: No such file or directory
```

Databricksランタイムには`libsndfile`がインストールされていないのでインストールが必要というオチでした。

https://community.databricks.com/s/question/0D58Y00009Xjx9sSAB/issue-in-importing-librosa-library-while-using-databricks-runtime-engine-112

[initスクリプト](https://qiita.com/taka_yayoi/items/88cb46be00a175085f87)を作成します。

```py:Python
dbutils.fs.put("/cluster-init/scripts/librosa_init_script.sh","""
#!/bin/bash
apt-get --yes install libsndfile1
""", True)
```

クラスターでinitスクリプトを設定します。
![Screenshot 2023-01-19 at 16.47.07.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1168882/c9b5afe8-a12d-309c-55ee-17a2cdc81214.png)

librosaも[クラスターライブラリ](https://qiita.com/taka_yayoi/items/9407356caadea3dfb47c)としてインストールしてしまいます。
![Screenshot 2023-01-19 at 16.47.56.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1168882/23db97a3-50ea-3347-c18e-109fc6ad436c.png)

サンプルプログラムを実行します。

```py:Python
# Beat tracking example
import librosa

# 1. Get the file path to an included audio example
filename = librosa.example('nutcracker')

# 2. Load the audio as a waveform `y`
#    Store the sampling rate as `sr`
y, sr = librosa.load(filename)

# 3. Run the default beat tracker
tempo, beat_frames = librosa.beat.beat_track(y=y, sr=sr)

print('Estimated tempo: {:.2f} beats per minute'.format(tempo))

# 4. Convert the frame indices of beat events into timestamps
beat_times = librosa.frames_to_time(beat_frames, sr=sr)
```

無事動きました。
