こちらのアップデートです。

https://docs.gcp.databricks.com/release-notes/product/2023/july.html#functions-now-displayed-in-data-explorer-public-preview

> SQL and Python user-defined functions are now visible in Data Explorer. You can view function details and manage permissions using this new UI.
> SQLとPythonのユーザー定義関数がデータエクスプローラで表示されるようになりました。この新たなUIで関数の詳細を参照し、権限を管理することができます。

早速試します。

```sql:SQL
CREATE FUNCTION area(x DOUBLE, y DOUBLE) RETURNS DOUBLE RETURN x * y;
```

表示されました！
