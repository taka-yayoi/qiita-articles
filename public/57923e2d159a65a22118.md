# [カスタム計算のための詳細レベルの式](https://docs.databricks.com/aws/en/ai-bi/release-notes/2026#level-of-detail-expressions-for-custom-calculations)
**2026-01-19**
<p>詳細レベルの式を使用すると、ビジュアライゼーション内のディメンションとは無関係に集計の粒度を制御できます。ディメンションを固定した詳細レベルの式を使用して、ビジュアライゼーションのグループ化に関係なく、特定のディメンションで集計するか、より粗い詳細レベルの式を使用して、ディメンションを除外することでより高いレベルで集計します。一般的なユースケースとしては、全体の割合の計算、データセット全体の集計値との比較、コホートレベルのメトリクスの作成などがあります。詳細については、<a href="https://docs.databricks.com/aws/ja/dashboards/custom-calculations/level-of-detail">詳細レベルの式</a>を参照してください。</p>

**ユーザーへのインパクト**

Databricksユーザーは、カスタム計算のための詳細レベルの式を利用できるようになりました。これにより、ビジュアライゼーション内のディメンションに依存せずに集計の粒度を制御できます。主な利点は以下の通りです：

1. **特定のディメンションでの集計**：ディメンションを固定した詳細レベルの式を使用することで、ビジュアライゼーションのグループ化に関係なく、特定のディメンションでデータを集計できます。

2. **より高いレベルでの集計**：より粗い詳細レベルの式を使用することで、ディメンションを除外し、より高いレベルでデータを集計できます。

3. **応用例**：
   - 全体の割合の計算
   - データセット全体の集計値との比較
   - コホート（特定の共通特性を持つユーザーグループ）レベルのメトリクスの作成

詳細な情報や具体的な使用方法については、Databricksのドキュメント（https://docs.databricks.com/aws/ja/dashboards/custom-calculations/level-of-detail）を参照してください。

<p>2025年12月8日より前に発行されたオープンの受信者トークンのうち、2026年12月8日より後に有効期限が設定されているトークン、もしくは有効期限が設定されていないトークンは、自動的に2026年12月8日に失効します。現在、長期間もしくは無期限のトークンをお使いの場合、2026年12月8日以降に不整合が生じないように、インテグレーションを確認し、トークンを更新してください。</p>

3. **推奨される対応**: 長期または無期限のトークンを使用している場合、2026年12月8日以降に不整合が生じないように、インテグレーションの確認とトークンの更新を行うことを推奨します。

# [Genieの研究エージェント、ベンチマーク、および回答の改善](https://docs.databricks.com/aws/en/ai-bi/release-notes/2025#genie-research-agent-benchmark-and-answer-improvements)
**2025-12-04**
<ul>
<li><strong>明確化された質問の改善</strong>: ユーザーのプロンプトに意味的な曖昧さがある場合に、Genie が明確化のための質問を投げかける機能が改善されました。</li>

DatabricksのGenieに関するリリースノートの要点は以下の通りです。

3. **ベンチマークエラーの説明**：Genieが生成した回答の誤りの説明がLLMによりベンチマークで提供されるようになりました。
4. **回答の読みやすさの向上**：回答要約にクエリ結果の全ての詳細が含まれる場合、クエリ結果テーブルが自動的に省略され、読みやすさが向上しました。
5. **指示のより良い遵守**：Genieが一般的な質問に対する回答要約のフォーマットに関する指示をより効果的に遵守するようになりました。

これらの改善により、DatabricksユーザーはGenieの機能をより効果的に活用でき、より正確でわかりやすい回答を得られるようになります。

# [パーソナルアクセストークンの有効期限に関するメール通知](https://docs.databricks.com/aws/en/release-notes/whats-coming#email-notifications-for-expiring-personal-access-tokens)
**2025-12-04**
Databricksは近日、個人用アクセストークンの有効期限が切れる約7日前に、ワークスペースのユーザーに電子メール通知を送信するようになります。通知は、電子メールベースのユーザー名を持つワークスペースユーザー（サービスプリンシパルは含まない）にのみ送信されます。 同じワークスペース内の期限切れのトークンはすべて、1つの電子メールにまとめられます。

詳細は<a href="https://docs.databricks.com/aws/ja/admin/access-control/tokens">個人用アクセストークンの監視と取り消し</a>をご覧ください。

**ユーザーへのインパクト**

Databricksのパーソナルアクセストークンの有効期限に関するメール通知機能が近日導入されます。この変更によるDatabricksユーザーへの影響は以下の通りです：

1. **メール通知の受信**: ワークスペースユーザーのうち、メールアドレスをユーザー名として使用しているユーザーは、パーソナルアクセストークンの有効期限が切れる約7日前にメール通知を受け取ります。
2. **通知対象**: メールベースのユーザー名を持つワークスペースユーザーが対象で、サービスプリンシパルは対象外です。
3. **複数のトークンの通知**: 同じワークスペース内で有効期限が切れるトークンが複数ある場合、それらは1通のメールにまとめられて通知されます。
4. **トークン管理の参考資料**: 詳細については、Databricksのドキュメント「個人用アクセストークンの監視と取り消し」が参照可能です。

この機能により、ユーザーはパーソナルアクセストークンの有効期限を事前に把握し、期限切れによるアクセス中断を避けるためにトークンの更新などの対応を行うことができます。
