# [カスタム計算のための詳細レベルの式](https://docs.databricks.com/aws/en/ai-bi/release-notes/2026#level-of-detail-expressions-for-custom-calculations)
**2026-01-19**
<p>詳細レベルの式を使用すると、ビジュアライゼーション内のディメンションとは無関係に集計の粒度を制御できます。ディメンションを固定した詳細レベルの式を使用して、ビジュアライゼーションのグループ化に関係なく、特定のディメンションで集計するか、より粗い詳細レベルの式を使用して、ディメンションを除外することでより高いレベルで集計します。一般的なユースケースとしては、全体の割合の計算、データセット全体の集計値との比較、コホートレベルのメトリクスの作成などがあります。詳細については、<a href="https://docs.databricks.com/aws/ja/dashboards/custom-calculations/level-of-detail">詳細レベルの式</a>を参照してください。</p>

**ユーザーへのインパクト**

Databricksユーザーは、カスタム計算のための詳細レベルの式を利用できるようになりました。これにより、ビジュアライゼーション内のディメンションに依存せずに集計の粒度を制御できます。主な利点は以下の通りです：

1. **特定のディメンションでの集計**：ディメンションを固定した詳細レベルの式を使用することで、ビジュアライゼーションのグループ化に関係なく、特定のディメンションでデータを集計できます。

2. **より高いレベルでの集計**：より粗い詳細レベルの式を使用することで、ディメンションを除外し、より高いレベルでデータを集計できます。

3. **応用例**：
   - 全体の割合の計算
   - データセット全体の集計値との比較
   - コホート（特定の共通特性を持つユーザーグループ）レベルのメトリクスの作成

詳細な情報や具体的な使用方法については、Databricksのドキュメント（https://docs.databricks.com/aws/ja/dashboards/custom-calculations/level-of-detail）を参照してください。

# [Power BIの新規接続におけるデフォルトのドライバーがADBCに変更になります。](https://docs.databricks.com/aws/en/release-notes/whats-coming#adbc-will-become-the-default-driver-for-new-power-bi-connections)
**2026-01-15**
2月から、Power BI Desktop または Power BI Service で作成された新しい接続では、デフォルトで Arrow Database Connectivity（ADBC）ドライバーが自動的に使用されます。既存の接続では、手動で ADBC に更新しない限り、引き続き ODBC が使用されます。

新しい接続でも ODBC を引き続き使用したい場合は、2 つの選択肢があります。

1. 接続を作成するときに、**実装** に `default` を選択します。
2. Power BI Desktop で ADBC のプレビュー機能を無効にすると、すべての新しい接続で ODBC がデフォルトに戻ります。

ADBC の詳細については、[Power BI 用 Arrow Database Connectivity (ADBC) ドライバー](/aws/ja/partners/bi/power-bi-adbc) と [ADBC リポジトリの Databricks ドライバー](https://github.com/apache/arrow-adbc/blob/main/csharp/src/Drivers/Databricks/readme.md) を参照してください。

**ユーザーへのインパクト**

このリリースノートは、Power BIとDatabricksの統合に関する変更を伝えています。以下はDatabricksユーザーへの影響です：

- 2月以降にPower BI DesktopまたはPower BI Serviceで新規にDatabricksへの接続を作成する場合、デフォルトでArrow Database Connectivity（ADBC）ドライバーが使用されます。
- 既存の接続はODBCを使用し続けますが、手動でADBCに更新することが可能です。
- ユーザーが新規接続でODBCを引き続き使用したい場合、2つの選択肢があります：
  1. 接続作成時に「実装」に`default`を選択する。
  2. Power BI Desktopのプレビュー機能でADBCを無効にすることで、すべての新規接続でODBCがデフォルトになります。
- ADBCの詳細については、指定されたリンク先のドキュメントを参照することが推奨されています。

つまり、DatabricksユーザーはPower BIとの接続において、新しいドライバーADBCの使用をデフォルトで期待されること、および既存の接続や特定の設定によるODBCの継続使用についての選択肢が提供されていることを理解する必要があります。
