# [カスタム計算のための詳細レベルの式](https://docs.databricks.com/aws/en/ai-bi/release-notes/2026#level-of-detail-expressions-for-custom-calculations)
**2026-01-19**
<p>詳細レベルの式を使用すると、ビジュアライゼーション内のディメンションとは無関係に集計の粒度を制御できます。ディメンションを固定した詳細レベルの式を使用して、ビジュアライゼーションのグループ化に関係なく、特定のディメンションで集計するか、より粗い詳細レベルの式を使用して、ディメンションを除外することでより高いレベルで集計します。一般的なユースケースとしては、全体の割合の計算、データセット全体の集計値との比較、コホートレベルのメトリクスの作成などがあります。詳細については、<a href="https://docs.databricks.com/aws/ja/dashboards/custom-calculations/level-of-detail">詳細レベルの式</a>を参照してください。</p>

**ユーザーへのインパクト**

Databricksユーザーは、カスタム計算のための詳細レベルの式を利用できるようになりました。これにより、ビジュアライゼーション内のディメンションに依存せずに集計の粒度を制御できます。主な利点は以下の通りです：

1. **特定のディメンションでの集計**：ディメンションを固定した詳細レベルの式を使用することで、ビジュアライゼーションのグループ化に関係なく、特定のディメンションでデータを集計できます。

2. **より高いレベルでの集計**：より粗い詳細レベルの式を使用することで、ディメンションを除外し、より高いレベルでデータを集計できます。

3. **応用例**：
   - 全体の割合の計算
   - データセット全体の集計値との比較
   - コホート（特定の共通特性を持つユーザーグループ）レベルのメトリクスの作成

詳細な情報や具体的な使用方法については、Databricksのドキュメント（https://docs.databricks.com/aws/ja/dashboards/custom-calculations/level-of-detail）を参照してください。

<ul>

これらの変更は、データの管理とアクセスに影響を与える可能性があるため、ユーザーはテーブル設定の確認と調整が必要です。特に、長い履歴データにアクセスしている場合は、設定の見直しが推奨されます。

**2025-12-19**
<p>2025 年 12 月 18 日以降に作成された Databricks アカウントは、DBFS ルートとマウントへのアクセス、Hive メタストア、ノー分離共有コンピュートなどの特定の従来の機能にアクセスできなくなります。これらのアカウントは、統合されたガバナンスとエンタープライズレベルのセキュリティのために Unity Catalog のみを使用します。</p>
<p>この動作により、既存の Databricks アカウントで利用可能なアカウント設定の<strong>従来の機能を無効にする</strong>が強制されます。 <a href="https://docs.databricks.com/aws/ja/admin/account-settings/legacy-features">新しいワークスペースでのレガシー機能へのアクセスを無効にする</a>を参照してください。</p>

**ユーザーへのインパクト**

2025年12月18日以降に作成される新しいDatabricksアカウントは、DBFSルート、Hiveメタストア、ノー分離共有コンピュートなどのレガシー機能にアクセスできなくなり、Unity Catalogのみを使用するようになります。既存のアカウントも将来的には「従来の機能を無効にする」設定が強制される可能性があります。旧機能を使用している場合は、Unity Catalogへの移行を検討する必要があります。

# [Delta Sharing受信者の監査ログイベントの更新リクエストパラメータ。](https://docs.databricks.com/aws/en/release-notes/product/2025/december#update-request-parameters-for-delta-sharing-recipient-audit-log-events)
**2025-12-19**
<p>Delta Sharing受信者に対して、<code>deltaSharingProxy*</code>監査ログイベントには、これまでは<code>share_name</code>（以前は<code>share</code>と呼ばれていました）に加えて、<code>catalog_name</code>リクエストパラメータも含まれるようになりました。<a href="https://docs.databricks.com/aws/ja/admin/account-settings/audit-logs#recipient">Delta Sharing受信者イベント</a>をご覧ください。</p>

**ユーザーへのインパクト**

Delta Sharing受信者に対する監査ログイベント`deltaSharingProxy*`に、`share_name`に加えて`catalog_name`リクエストパラメータが含まれるようになりました。これにより、Delta Sharing受信者の操作に関するより詳細な監査情報が提供されます。ユーザーは、これらの追加の監査ログイベントを参照することで、Delta Sharing受信者のアクティビティをより詳細に追跡および監視できるようになります。影響を受けるログイベントについては、[ドキュメント](https://docs.databricks.com/aws/ja/admin/account-settings/audit-logs#recipient)を参照してください。

# [ODBCドライバーのダウンロードに使用する公開URLを無効にします。](https://docs.databricks.com/aws/en/release-notes/whats-coming#public-urls-for-odbc-driver-downloads-will-be-disabled)
**2025-12-18**
近日リリース予定のバージョンにおいて、自動化された <a href="https://docs.databricks.com/https://www.databricks.com/spark/odbc-drivers-download">Apache Spark ODBC ドライバー</a>のダウンロードのためのパブリック URL が無効化されます。この変更後、自動化されたプロセスを含むすべてのドライバーのダウンロードに認証が必要になります。これにより、認証なしで直接パブリックリンクを使用してApache Spark ODBCドライバーをダウンロードする自動化されたプロセスが動作しなくなります。

**ユーザーへのインパクト**

近日リリース予定のバージョンで、Apache Spark ODBCドライバーのダウンロードに使用される公開URLが無効になります。これにより、認証なしで直接パブリックリンクを使用してApache Spark ODBCドライバーをダウンロードする自動化されたプロセスが動作しなくなります。つまり、DatabricksユーザーはODBCドライバーをダウンロードする際に認証が必要になります。自動化されたプロセスを使用している場合は、認証を組み込むように変更する必要があります。
