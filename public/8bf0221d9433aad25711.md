[Databricks Academy](https://www.databricks.com/learn/training)は、データ&AIのペルソナ向けのトレーニングや認定試験を提供しており、ユーザーや企業は少ない時間でより生産的かつ多くのことができるようにしています。データアナリシスからMLに至るまで、ユーザーは自身の経験レベルやテクノロジーに関係なく、新たなスキルをマスターすることができます。我々はお客さまが、我々の認定試験に業火することで、自分たちの組織、更には自分のキャリアに対しても大きなインパクトをもたらしているのを目撃しています。

本日、我々はユーザーの皆様が日々の仕事をより効率的に行い、企業がパフォーマンスを増加するのをお手伝いするために、[データアナリシス](https://www.databricks.com/jp/product/databricks-sql)、[データエンジニアリング](https://www.databricks.com/jp/product/data-lakehouse)、[機械学習](https://www.databricks.com/jp/product/machine-learning)の概要を説明する無料のコースを発表できることを嬉しく思っています。Databricksの認定を受けることで、ユーザーは最も困難なデータ&AIの問題を解決する役に立つ知識に対して自信を深めることができます。

お客さまたちはすでに価値を確認しています。Valorem ReplyのパートナーであるAndrew Fletcherはこう述べています。「我々は認定試験が個人や組織にとって真に価値のあるものだと考えています。個人に対しては、キャリアの過程で彼らを認定プロセスに組み込んでいます。これは構造化されており、製品の複雑性を理解し始めることができ、チームとしてビジネス課題を解決し、信頼性を確立することができます。」

# あなたのスキルとニーズに合わせてトレーニングを仕立てましょう

それぞれの認定試験の概要を説明するコースには、ユーザーが数多くのキー領域で成長し、自身の知識を試す助けになる学習目的が設定されています。以下の認定試験概要コースは、[Databricks Academy](https://www.databricks.com/learn/training/login)から無料で利用することができます。

- **Databricks Certified Associate Developer for Apache Spark Exam**には以下が含まれます。
    - Apache Sparkアーキテクチャの基礎
    - カラムの選択、名称変更、操作、行のフィルタリング、削除、ソート、集計、データフレームの読み書き、パーティショニング、Spark SQL関数を用いたUDFの操作を含むそれぞれのデータ操作タスクを完了するためにSparkデータフレームの適用。

- **Databricks Certified Data Analyst Associate Exam**には以下が含まれます。
    - Databricks SQLの概要と機能
    - Databricksのツールを用いたデータの管理とベストプラクティス
    - レイクハウスでのタスクを完了するための構造化クエリー言語(SQL)の活用
    - プロダクションレベルのデータビジュアライゼーションとダッシュボードの作成
    - 一般的なデータ分析課題を解決するための分析アプリケーションの開発

- **Databricks Certified Data Engineer Associate Exam**には以下が含まれます。
    - Databricksレイクハウスプラットフォームとツールの活用
    - Apache Spark SQLとPythonを用いたETLパイプラインの構築
    - インクリメンタルなデータ処理
    - データエンジニアリングアプリケーションのためのプロダクションパイプライン、Databricks SQLのクエリーとダッシュボードの構築

- **Databricks Certified Data Engineer Professional Exam**には以下が含まれます。
    - Databricksプラットフォームと開発ツールのメリットと活用
    - SparkとDelta Lake APIを用いた最適化されクレンジングされたデータ処理パイプラインの構築
    - 一般的なデータモデリングのコンセプトに関する知識を用いたレイクハウスへのデータモデリング
    - デプロイメント前にデータパイプラインのセキュリティ、信頼性、監視、テストを保証

- **Databricks Certified Machine Learning Associate Exam**には以下が含まれます。
    - 機械学習ワークフローにおけるDatabricks Machine Learningとその機能の活用
    - 機械学習ワークフローにおける適切な実装の意思決定
    - Spark MLとその他のツールを用いた大規模機械学習ソリューションの実装
    - 古典的な機械学習モデルの特性に対する高度なスケーリングの理解

- **Databricks Certified Machine Learning Professional Exam**には以下が含まれます。
    - 機械学習のエクスペリメントとバージョンコントロールの管理
    - 機械学習モデルライフサイクルの管理
    - 機械学習モデルのデプロイに対する戦略の実装
    - ドリフト検知のためのモデルモニタリング

# 今日から始めましょう

現在Databricksを利用されているお客様は[Databricks Academy](https://www.databricks.com/learn/training/login)にログインすることができ、Catalog 001の下でDatabricks認定試験概要のコースを探し出すことができます。

その他のデータ&AIのプロフェッショナルやファンの方もDatabricksアカデミーのアカウントを作成することで概要コースにアクセスすることができます。ログインしたら、Catalog DB005aで概要コースにアクセスすることができます
