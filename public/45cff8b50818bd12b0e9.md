こちらを書いてから、

https://qiita.com/taka_yayoi/items/fa16e38bcc1ff68ba515

こちらの記事を思い出しました。

https://qiita.com/taka_yayoi/items/5e070431d256281043fe

上の記事ではSQLエディターでRAGの挙動を試しましたが、Genieスペースでも使えるのではないかと思い立ちました。

例によって自分のQiitaの記事のベクトル検索インデックスを作成しておきます。
![Screenshot 2025-07-01 at 13.34.17.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1168882/4d7bb159-f632-4294-b6d3-115b92afd6f6.png)

Genieスペースを作成します。普通にベクトル検索インデックスも追加できますね。
![Screenshot 2025-07-01 at 13.11.19.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1168882/ddf13913-0043-4c9b-bfec-8b95842163d6.png)

[こちら](https://qiita.com/taka_yayoi/items/fa16e38bcc1ff68ba515)で行ったようにSQLクエリーのサンプルを登録します。

以下のクエリーを指定しています。パラメータ化しています。

```sql
SELECT
  ai_query(
    'databricks-claude-sonnet-4',
    "あなたはDatabricksの専門家です。" || :param || "という質問に対して" || (
      SELECT
        body_excerpt
      FROM
        VECTOR_SEARCH(
          index => "takaakiyayoi_catalog.vector_search.vs_qiita",
          query => :param,
          num_results => 1
        )
    ) || "という文脈が得られています。質問と得られた文脈に基づいて、簡潔かつ適切な回答を生成してください。文脈が得られない場合には「わからない」と回答してください。"
  ) AS response
```

適切にクエリーが呼び出されるように説明文にも注意します。指定しているパラメータと合わせて`「databricksとは」という質問に対して文脈に基づいた回答を生成する`としています。

**プレビュー**で動作確認します。
![Screenshot 2025-07-01 at 13.42.22.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1168882/c355bf14-80f7-4572-95d5-9c27f3447367.png)

動作確認できたのでGenieとチャットしてみると、[信頼できる資産](https://docs.databricks.com/aws/ja/genie/trusted-assets)としてクエリーが特定されてRAGとして処理が行われました。

![Screenshot 2025-07-01 at 13.43.11.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1168882/2d87935b-907f-41f6-9f92-c2cb817da6ac.png)

Genie + AI関数の組み合わせには可能性を感じますね。

:::note info
**注意**
これがGenieで意図される使い方かと聞かれると、微妙なところがありますのでご参考まで。ただ、GenieからAI関数を利用できるようにすることで、処理の幅や活用形態が広がることは間違いありません。
:::
