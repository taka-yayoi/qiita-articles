# ファネルチャートとは

ファネルチャート(Funnel Chart)は、段階的なプロセスにおける数値の減少を視覚的に表現するグラフです。漏斗(ファネル)の形をしていることからこの名前が付けられています。

## 主な特徴

ファネルチャートは、プロセスの各段階で徐々に数値が絞り込まれていく様子を表現します。上部が広く、下部に向かって狭くなる逆三角形の形状で、各段階の幅がその段階の数値や割合を表しています。

## 一般的な用途

営業・マーケティング分野では、見込み客から実際の購入に至るまでの転換率を可視化するのに頻繁に使用されます。例えば、ウェブサイト訪問者数から始まり、商品ページ閲覧、カート追加、購入完了という各段階での人数の推移を示すことができます。

採用プロセスでは、応募者総数から書類選考通過者、面接通過者、最終的な採用者数への絞り込みを表現するのに適しています。

品質管理においては、製造プロセスの各段階での歩留まり率や、不良品の除外プロセスを視覚化する際にも活用されます。

# ファネルチャートのデータの準備

マニュアルに記載のデータでも良かったのですが、より雰囲気を掴めるようにダミーデータを作りました。コードはアシスタントにお願いしました。

> ファネルチャートの可視化に適したサンプルデータをテーブルに保存

```py
from pyspark.sql import Row

# ファネルチャート用サンプルデータ
sample_data = [
    Row(stage="訪問", count=1000),
    Row(stage="会員登録", count=600),
    Row(stage="商品閲覧", count=400),
    Row(stage="カート追加", count=200),
    Row(stage="購入", count=100)
]

funnel_df = spark.createDataFrame(sample_data)

# テーブルとして保存
funnel_df.write.mode("overwrite").saveAsTable("takaakiyayoi_catalog.default.funnel_sample")
```
