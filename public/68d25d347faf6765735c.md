過去数ヶ月を通じて、我々は皆様のフィードバックを収集し続けており、Databricksアシスタントのレスポンスの品質と全体的なユーザー体験の両方にフォーカスし続けています。本日、プロンプトエンジニアリングをシンプルにし、皆様のワークフローを加速するために全てが設計されたパワフルな新機能が搭載された、さらに高度になったDatabricksアシスタントをご説明できることを嬉しく思っています。

キーとなる改善点には以下が含まれます:

- [**@によるテーブルメンション**](https://docs.databricks.com/ja/notebooks/use-databricks-assistant.html#reference-tables-in-prompts-using-): ユーザーは、アシスタントのプロンプト内で@を用いてテーブルをメンションすることができ、より正確な提案ができるようにアシスタントが適切なテーブルを参照するようにできます。
- **インラインの改善**: ユーザーはセル内の特定の行をハイライトし、選択された行やクエリーのセクションにフォーカスしたインラインのアシスタントを初期化できるようになりました。
- [**アシスタント利用ログ**](https://docs.databricks.com/ja/admin/system-tables/assistant.html): 管理者やマネージャがアシスタントの利用量とエンゲージメントを追跡できるように、新たなシステムテーブル(`system.access.assistant_events`)が導入されました。
- [**ジョブ失敗の診断**](https://docs.databricks.com/ja/notebooks/use-databricks-assistant.html#diagnose-errors-in-jobs-public-preview): ワークフロー/ジョブのページから直接ジョブのエラーを診断します。
- **AI生成フィルター**: 新たな結果テーブルで自然言語のみを用いてフィルターを作成します。
- **SQLクエリーの最適化**: 潜在的に非効率的なSQLクエリーを最適化するためにアシスタントを活用します。
- [**アシスタントのクイックフィックス**](https://qiita.com/taka_yayoi/items/07deeeb447d4d7511311): 特定のセルのエラーに対して、アシスタントは1-3秒で単一行の修正を自動で提案します。

# @テーブル

直接的なレスポンスを改善するために、ユーザーはアシスタントのプロンプトでテーブルを@でメンションできます。@を入力すると、ユーザーには適切性の順序でソートされたテーブルのリストが提供されます。また、ユーザーはプロンプトで複数のテーブルを@でメンションすることができます。右側ではユーザーは完全なディレクトリ/カタログのパスを参照することができます。

![](https://www.databricks.com/sites/default/files/inline-images/image7_9.png?v=1729625219)

# インラインの改善

これまでは、インラインアシスタントはセル全体、あるいはクエリー全体に対してしか操作が行えず、多くの場合、小規模な修正のみが必要な場合においても、コードブロック全体を再生成していました。今回、セルやクエリーの特定の行をハイライトする能力を導入し、アシスタントに変更して欲しい箇所を正確に指示できるようになりました。この機能強化によって、皆様にレスポンスの生成に対するさらなるコントロールと高速化を提供することになります。

![](https://www.databricks.com/sites/default/files/inline-images/refactorifshighres.gif?v=1729805329)

# アシスタント使用ログ

管理者やマネージャは、新たに導入されたアシスタントのシステムテーブル(`system.access.assistant_events`)によって、アシスタントの導入度合いとエンゲージメントを追跡できるようになりました。このテーブルのそれぞれの行はサイドパネルやインラインチャットのユーザーのやり取りを記録します。

また、以下のような情報をクイックに可視化できるようにするために、カスタムのサンプルダッシュボードを作成しました:

- 日毎、月毎のアクティブユーザー数
- ワークスペースごとのアクティブユーザー数
- 全体的なトップユーザー
- データ送信数: ワークスペースごと、全体

![](https://www.databricks.com/sites/default/files/inline-images/image4_18.png?v=1729625219)

# ジョブ失敗の診断

ジョブが失敗した際にエラーをより理解し、修正できるようにするために、アシスタントを直接利用できるようになりました。

![](https://www.databricks.com/sites/default/files/inline-images/Screenshot-2024-10-22-at-11.05.06-AM.png?v=1729625219)

# AI生成フィルター

自然言語を用いて、結果の出力をクイックにフィルタリングするためにアシスタントを活用します。フィルタリングには文の再実行は不要であり、特定の洞察にドリルダウンするためにチェーンさせることもできます。

![](https://www.databricks.com/sites/default/files/inline-images/AI-Generated-Filters.gif?v=1729625219)

# SQLの効率性の改善

非効率的なSQLクエリーを改善するために、構文ハイライトの警告と`/optimize`コマンドを活用します。リアルタイムで最適化のポップアップが表示されますので、実行前に非効率的な箇所を特定するのに役立ちます。

![](https://www.databricks.com/sites/default/files/inline-images/Improeve-SQL-Efficiency.gif?v=1729625219)

# アシスタントのクイックフィックス

[クイックフィックス](https://qiita.com/taka_yayoi/items/07deeeb447d4d7511311)は、LLMによって対処できることに我々が自信を持っている、SQLとPythonにおけるセルの一般的なエラーを自動で解決するパワフルな新機能です。これには、末尾のカンマ、タイポ、構文間違いなどが含まれます。スピードに重点を置いて開発されているので、クイックフィックスはたった1-3秒で提案を提供し、キーボードのショートカットとシームレスにインテグレーションされています。

![](https://www.databricks.com/sites/default/files/inline-images/Quick-Fix-GroupByFaster.gif?v=1729625219)
