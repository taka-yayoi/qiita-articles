[Machine learning and deep learning environment setup guide \| Databricks on AWS](https://docs.databricks.com/applications/machine-learning/environment-setup.html) [2021/6/16時点]の翻訳です。

[Databricks機械学習ランタイム](https://qiita.com/taka_yayoi/items/824b507019d3ade7eedc)(Databricks Runtime ML)は、機械学習、データサイエンスに最適化されたすぐに利用できる環境です。Databricks Runtime MLには、TensorFlow、PyTorch、Horovod、scikit-learn、XGBoostを含む外部ライブラリが多く含まれており、[XGBoost](https://docs.databricks.com/applications/machine-learning/train-model/xgboost.html)におけるGPUアクセラレーション、[HorovodRunner](https://docs.databricks.com/applications/machine-learning/train-model/distributed-training/horovod-runner.html)による分散ディープラーニング、[Databricks File System \(DBFS\) FUSE mount](https://docs.databricks.com/applications/machine-learning/load-data/index.html#store-files-for-data-loading-and-model-checkpointing)を用いたモデルのチェックポイントのような性能改善のための拡張が行われています。

Databricks Runtime MLを使用するには、[クラスターを作成](https://qiita.com/taka_yayoi/items/d36a469a1e0c0cebaf1b)する際にMLバージョンのランタイムを選択します。

# 追加ライブラリのインストール

お使いのノートブックやクラスターでカスタムの環境を作成するために、追加の[ライブラリ](https://qiita.com/taka_yayoi/items/d3a46efdc1ad01a581d0)をインストールすることができます。

- クラスターで実行する全てのノートブックで利用できるライブラリを作成するために、[クラスターライブラリを作成](https://qiita.com/taka_yayoi/items/d3a46efdc1ad01a581d0#2-%E3%82%AF%E3%83%A9%E3%82%B9%E3%82%BF%E3%83%BC%E3%83%A9%E3%82%A4%E3%83%96%E3%83%A9%E3%83%AA)します。クラスター作成時にライブラリをインストールするために、[init script](https://docs.databricks.com/clusters/init-scripts.html#cluster-scoped-init-script)を使用することもできます。
- 特定のノートブックセッションでのみ利用できるライブラリをインストールするには、[ノートブックスコープのPythonライブラリ](https://qiita.com/taka_yayoi/items/d3a46efdc1ad01a581d0#3-%E3%83%8E%E3%83%BC%E3%83%88%E3%83%96%E3%83%83%E3%82%AF%E3%82%B9%E3%82%B3%E3%83%BC%E3%83%97%E3%83%A9%E3%82%A4%E3%83%96%E3%83%A9%E3%83%AA)を使用します。

# GPU有効化クラスターの作成

ディープラーニングタスクを高速化するために、GPUが有効化されたクラスターを作成することができます。GPUが有効化されたDatabricksクラスターを作成するには、[GPU\-enabled clusters](https://docs.databricks.com/clusters/gpu.html#gpu-clusters)を参照ください。Databricks機械学習ランタイムには、GPUハードウェアドライバーとCUDAのようなNVIDIAライブラリが含まれています。
