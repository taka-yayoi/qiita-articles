こちらで紹介されている新機能、Identity列を試してみました。

https://qiita.com/taka_yayoi/items/f4076d1be4ffe017564f

[Databricks SQL](https://www.databricks.com/jp/product/databricks-sql)でテーブルを作成して、データをインサートしていきます。

# Databricks SQLにアクセス

Databricksワークスペースにログインし、サイドメニューのペルソナスイッチャーで**SQL**を選択します。
![Screen Shot 2022-08-16 at 8.15.46.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1168882/7c4e8e7e-473c-240f-96b8-6aebd6c766fa.png)

# テーブルの作成

1. サイドメニューから**クエリ**を選択します。
![Screen Shot 2022-08-16 at 8.16.43.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1168882/cdd89491-050a-1cc0-3b3e-2817bf6a8c55.png)
1. 画面右上の**クエリーを作成**をクリックします。
![Screen Shot 2022-08-16 at 8.17.23.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1168882/74b55483-4cf9-5441-21bf-afa3c1510c16.png)
1. クエリーエディタが表示されます。
![Screen Shot 2022-08-16 at 8.21.03.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1168882/52719fef-a6f5-92fc-00d2-75e3e7152173.png)
1. 以下のクエリーを入力します。`USE`で指定するデータベースは適宜変更してください。

    ```sql:SQL
    USE `20210826_workshop_takaakiyayoidatabrickscom`;
    
    CREATE OR REPLACE TABLE demo (
      id BIGINT GENERATED ALWAYS AS IDENTITY,
      product_type STRING,
      sales BIGINT
    );
    ```

1. **すべてを実行**をクリックしてテーブルを作成します。クエリーが成功すると`demo`テーブルが作成されます。
![Screen Shot 2022-08-16 at 8.23.02.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1168882/f3861a7e-9c6b-f4d5-7a94-192855dd36b1.png)
1. この時点ではテーブルは空です。
![Screen Shot 2022-08-16 at 8.27.00.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1168882/b32bd5dc-56d0-e724-83c1-1be18fa17f6f.png)

# 行のインサート

1. ダミーの行をインサートします。

    ```sql:SQL
    USE `20210826_workshop_takaakiyayoidatabrickscom`;
    INSERT INTO demo (product_type, sales)
    VALUES ("Batteries", 150000);
    INSERT INTO demo (product_type, sales)
    VALUES ("Chargers", 200000);
    ```

1. テーブルを確認します。

    ```sql:SQL
    SELECT * FROM `20210826_workshop_takaakiyayoidatabrickscom`.demo ORDER BY id ASC;
    ```
    `id`列にインサートされた順の連番が振られていることがわかります。
![Screen Shot 2022-08-16 at 8.28.58.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1168882/336da2e8-da10-4212-7be9-2b369b189c89.png)

1. さらにダミーの行をインサートします。

    ```sql:SQL
    USE `20210826_workshop_takaakiyayoidatabrickscom`;
    INSERT INTO demo (product_type, sales)
    VALUES ("Papers", 50000);
    INSERT INTO demo (product_type, sales)
    VALUES ("Repair", 1200000);
    ```

1. テーブルを確認します。

    ```sql:SQL
    SELECT * FROM `20210826_workshop_takaakiyayoidatabrickscom`.demo ORDER BY id ASC;
    ```
    ![Screen Shot 2022-08-16 at 8.30.35.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1168882/c6868fbc-8159-d09c-3b11-04f4d6e40c72.png)

クリーンアップするにはテーブルをドロップしてください。

```sql:SQL
DROP TABLE `20210826_workshop_takaakiyayoidatabrickscom`.demo
```

このようにIdentity列を使うことで、データベースでは当たり前の主キー・外部キーによるテーブル結合がデータレイク上のデータでも容易に行えるようになります。
