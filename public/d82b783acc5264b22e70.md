# DatabricksにおけるAI/BI Genieスペースとは？

現在パブリックプレビューである、AI/BI Genieによって、ドメイン専門家はデータセット、サンプルのクエリー、テキストのガイドでGenieスペースを設定できます。AI/BI Genieは、自然言語の入力の解釈、設定されたデータセットから適切なデータを取得するSQLクエリーへの変換を行うことで動作します。

この機能は、データの変更や新たな質問が提示されるにつれて、その意味的な知識ベースを更新することで進化し、深い技術的な専門性なしにデータドリブンの洞察を得たいと考えている非技術者にとってのパワフルのツールとなるように設計されています。詳細に関しては[こちら](https://learn.microsoft.com/ja-jp/azure/databricks/genie/)のリンクを訪問してみてください。

# DatabricksにおけるAI関数

Databricksでは、以下のようなGenieスペースで活用できるAI関数のスイートを提供しています:

- [ai\_mask](https://learn.microsoft.com/ja-jp/azure/databricks/sql/language-manual/functions/ai_mask)
- [ai\_query](https://learn.microsoft.com/ja-jp/azure/databricks/sql/language-manual/functions/ai_query)

完全なリストについては[こちら](https://learn.microsoft.com/ja-jp/azure/databricks/large-language-models/ai-functions)をご覧ください。

DatabricksでAI関数とGenieスペースを組み合わせることで、データ分析を誰でも利用できるようにするための大きな一歩を踏み出すことができます。自然言語でのやり取りを可能にすることで、自身たちのデータの完全なポテンシャルを活用するために、Databricksはすべての技術レベルにあるユーザーを支援します。これらのツールを探索すると、イノベーションを加速し、自信を持ってデータに基づく意思決定を行い、AIによって形作られる有望な将来を覗き見ることができます。

我々のサンプルシナリオを理解することから始めましょう。自身の店舗や製品における在庫に関してより理解したいと考えているサプライチェーンのディレクターであるLucyがいるものとしましょう。一緒に働いているデータチームが彼女のために、厳選された以下のテーブルを持つGenieデータルームを作成しました。

1. **Harmonised_retailer_inventory_dc** - このテーブルには、小売業者向けの在庫配送センターに関するデータが格納されています。
1. **Harmonised_retailer_inventory_store** - このテーブルには、小売店舗、在庫、関連する詳細情報が含まれています。
1. **Harmonised_retailer_sales** - このテーブルにはさまざまな小売業者からの売上データが含まれています。

これらのデータには、[こちら](https://marketplace.databricks.com/details/0a82f0ae-1709-4313-80f0-cdc8b29382bb/Crisp-Inc_CPG-Retail-and-Distributor-Data-Samples)のDatabricks Marketplaceからアクセスできます。

まとめると、これらのテーブルには、すべての店舗と配送センターにおけるそれぞれの製品の在庫レベル、それぞれの店舗の売上データが格納されています。また、このデータには場所、店舗と配送センターの名前も含まれています。これでLucyは、SQLクエリーを記述することなしに、自然言語でシンプルに会話するだけで、店舗や製品ごとの売上パフォーマンスに関して質問を行い、製品、店舗、配送センターにおける在庫レベルとの相関関係を構築できるようになります。

# AI_QUERY

また、以下の例のようにAI_QUERYのようなAI関数をGenieがどのように活用するのかを説明するためのクエリーを実行できます。

![](https://miro.medium.com/v2/resize:fit:1400/format:webp/0*m1wocIv6vvEBRjTy)

このレスポンスで生成されたクエリーも確認しましょう。

```sql
WITH ClassifiedProducts AS (
 SELECT
   product,
   main_category,
   detailed_description,
   ai_query(
     "databricks-meta-llama-3-70b-instruct",
     CONCAT(
       "Using the product_description as input, recategorize this product into the following categories: Battery-operated, manual. Limit your response to just one of the elements in that list and provide no explanation of your choice. Here is the product_description: ",
       detailed_description
     )
   ) AS classification
 FROM
   mlops_pj.crisp_data_room.product_description
 WHERE
   main_category = 'Toothbrush'
),
SalesData AS (
 SELECT
   hs.product,
   hs.store,
   hs.date_key,
   hs.sales_quantity,
   hs.sales_amount,
   (hs.sales_quantity * hs.sales_amount) AS total_revenue
 FROM
   crisp_retail_demo.examples.harmonized_retailer_sales hs
 WHERE
   hs.store = 'STORE 06067'
   AND hs.date_key BETWEEN '2022-10-01'
   AND '2022-10-31'
)
SELECT
 cp.classification,
 SUM(sd.total_revenue) AS total_sales
FROM
 ClassifiedProducts cp
 JOIN SalesData sd ON cp.product = sd.product
GROUP BY
 cp.classification
```
