こちらのDatabricks SQL Statement Execution APIを試してみます。

https://qiita.com/taka_yayoi/items/140b0239709ff06a4955

# 要件

- 稼働しているDatabricksワークスペース(プレミアム/エンタープライズプラン)
- [Databricks SQLウェアハウス](https://qiita.com/taka_yayoi/items/23d7789198c2dcd66381)
- [パーソナルアクセストークン](https://qiita.com/taka_yayoi/items/f5493a4169e95e1a7a61)

# 準備

1. [パーソナルアクセストークン](https://qiita.com/taka_yayoi/items/f5493a4169e95e1a7a61)を生成してメモしておきます。
1. アクセスするDatabricks SQLウェアハウスがなければ作成します。
1. SQLウェアハウスの画面にアクセスしてウェアハウスのIDをコピーしておきます。
![Screenshot 2023-03-08 at 10.14.42.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1168882/4932ea7b-78f8-937c-a223-1534506bb082.png)
1. [ワークスペースのホスト名](https://qiita.com/taka_yayoi/items/7127cabac70dd994fcba#%E3%83%AF%E3%83%BC%E3%82%AF%E3%82%B9%E3%83%9A%E3%83%BC%E3%82%B9%E3%81%AE%E3%82%A4%E3%83%B3%E3%82%B9%E3%82%BF%E3%83%B3%E3%82%B9%E5%90%8Durlid)をメモしておきます。`https://`や末尾の`/`は不要です。
1. REST APIを呼び出すマシンで環境変数を設定します。以下の例はMacでのターミナルで実行しています。SQL文は`SELECT * FROM hive_metastore.japan_covid_takaakiyayoidatabrickscom.covid_cases LIMIT 10`としています。

    ```bash
    export DATABRICKS_TOKEN='<パーソナルアクセストークン>'
    export DATABRICKS_HOST='<Databricksワークスペースのホスト名>'
    export DATABRICKS_SQL_WAREHOUSE_ID='<SQLウェアハウスID>'
    ```
1. curlを使ってREST APIを呼び出します。

    ```bash
    curl --request POST \
    https://${DATABRICKS_HOST}/api/2.0/sql/statements/ \
    --header "Authorization: Bearer ${DATABRICKS_TOKEN}" \
    --header "Content-Type: application/json" \
    --data '{
      "warehouse_id": "'"$DATABRICKS_SQL_WAREHOUSE_ID"'",
      "catalog": "samples",
      "schema": "tpch",
      "statement": "SELECT * FROM hive_metastore.japan_covid_takaakiyayoidatabrickscom.covid_cases LIMIT 10"
    }' | jq
    ```
