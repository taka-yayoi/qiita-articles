> **ネットワーク**
> このアーキテクチャでは、エージェントはグラフのノードとして定義されます。それぞれのエージェントは他のすべてのエージェントとコミュニケーションを行い、どのエージェントを次に呼び出すのかを決定することができます。このアーキテクチャは、明確なエージェントの階層構造を持たない問題や、エージェントの呼び出しに特定の順序がない問題に適しています。

以下でノートブックを実行していきますが、LMやMLflow連携などで手を入れています。

# マルチエージェントネットワーク

単一のエージェントは、通常、単一のドメイン内でいくつかのツールを使用して効果的に動作できますが、`gpt-4`のような強力なモデルを使用しても、多くのツールを使用するのは効果的ではない場合があります。

複雑なタスクに取り組む一つの方法は、「分割統治」アプローチです。各タスクやドメインに特化したエージェントを作成し、タスクを適切な「専門家」にルーティングします。これは[マルチエージェントネットワーク](https://langchain-ai.github.io/langgraph/concepts/multi_agent/#network)アーキテクチャの一例です。

このノートブックは、Wuらによる論文[AutoGen: Enabling Next-Gen LLM Applications via Multi-Agent Conversation](https://arxiv.org/abs/2308.08155)に触発され、LangGraphを使用してこれを行う方法の一例を示しています。

## ツールの定義

将来的にエージェントが使用するいくつかのツールも定義します。

```py
from typing import Annotated

from langchain_community.tools.tavily_search import TavilySearchResults
from langchain_core.tools import tool
from langchain_experimental.utilities import PythonREPL

tavily_tool = TavilySearchResults(max_results=5)

# 警告: これはローカルでコードを実行します。サンドボックス化されていない場合は安全でない可能性があります

repl = PythonREPL()


@tool
def python_repl_tool(
    code: Annotated[str, "チャートを生成するために実行するPythonコード。"],
):
    """これを使用してPythonコードを実行します。値の出力を確認したい場合は、
    `print(...)`で出力してください。これはユーザーに表示されます。"""
    try:
        result = repl.run(code)
    except BaseException as e:
        return f"実行に失敗しました。エラー: {repr(e)}"
    result_str = f"正常に実行されました:\n```python\n{code}\n```\n標準出力: {result}"
    return (
        result_str + "\n\nすべてのタスクが完了した場合は、FINAL ANSWERと応答してください。"
    )
```

## グラフの作成

ツールを定義し、いくつかのヘルパー関数を作成したので、以下に個々のエージェントを作成し、LangGraphを使用してそれらがどのように通信するかを指定します。

### エージェントノードの定義

次に、ノードを定義する必要があります。

まず、各エージェントのシステムプロンプトを作成するユーティリティを作成します。

```py
def make_system_prompt(suffix: str) -> str:
    return (
        "あなたは他のアシスタントと協力している有能なAIアシスタントです。"
        " 提供されたツールを使用して、質問に答えるために進めてください。"
        " 完全に答えられない場合は問題ありません。別のツールを持つ他のアシスタントが"
        " あなたが残したところから助けてくれます。進捗を得るために実行できることを実行してください。"
        " あなたまたは他のアシスタントが最終的な答えや成果物を持っている場合は、"
        " チームが停止することを知るために、応答の先頭にFINAL ANSWERと付けてください。"
        f"\n{suffix}"
    )
```

```py
from typing import Literal

from langchain_core.messages import BaseMessage, HumanMessage
from langchain_openai import ChatOpenAI
from langgraph.prebuilt import create_react_agent
from langgraph.graph import MessagesState, END
from langgraph.types import Command


llm = ChatOpenAI(model="gpt-4o-mini")


def get_next_node(last_message: BaseMessage, goto: str):
    if "FINAL ANSWER" in last_message.content:
        # どのエージェントも作業が完了したと判断した場合
        return END
    return goto


# リサーチエージェントとノード
research_agent = create_react_agent(
    llm,
    tools=[tavily_tool],
    prompt=make_system_prompt(
        "あなたはリサーチのみを行います。チャート生成を行う同僚と協力しています。"
    ),
)


def research_node(
    state: MessagesState,
) -> Command[Literal["chart_generator", END]]:
    result = research_agent.invoke(state)
    goto = get_next_node(result["messages"][-1], "chart_generator")
    # 人間のメッセージでラップします。すべてのプロバイダーが
    # 入力メッセージリストの最後にAIメッセージを許可するわけではありません
    result["messages"][-1] = HumanMessage(
        content=result["messages"][-1].content, name="researcher"
    )
    return Command(
        update={
            # リサーチエージェントの内部メッセージ履歴を他のエージェントと共有
            "messages": result["messages"],
        },
        goto=goto,
    )


# チャート生成エージェントとノード
# 注意: これは任意のコード実行を行います。サンドボックス化されていない場合は安全でない可能性があります
chart_agent = create_react_agent(
    llm,
    [python_repl_tool],
    prompt=make_system_prompt(
        "あなたはチャートのみを生成できます。リサーチを行う同僚と協力しています。"
    ),
)


def chart_node(state: MessagesState) -> Command[Literal["researcher", END]]:
    result = chart_agent.invoke(state)
    goto = get_next_node(result["messages"][-1], "researcher")
    # 人間のメッセージでラップします。すべてのプロバイダーが
    # 入力メッセージリストの最後にAIメッセージを許可するわけではありません
    result["messages"][-1] = HumanMessage(
        content=result["messages"][-1].content, name="chart_generator"
    )
    return Command(
        update={
            # チャートエージェントの内部メッセージ履歴を他のエージェントと共有
            "messages": result["messages"],
        },
        goto=goto,
    )
```

### グラフの定義

これで、すべてをまとめてグラフを定義できます！

```py
from langgraph.graph import StateGraph, START

workflow = StateGraph(MessagesState)
workflow.add_node("researcher", research_node)
workflow.add_node("chart_generator", chart_node)

workflow.add_edge(START, "researcher")
graph = workflow.compile()
```

## 呼び出し

グラフが作成されたので、それを呼び出すことができます！私たちのためにいくつかの統計をチャートにしてみましょう。

```py
events = graph.stream(
    {
        "messages": [
            (
                "user",
                "過去5年間の英国のGDPを取得し、それをラインチャートにしてください。"
                "チャートを作成したら、終了してください。",
            )
        ],
    },
    # グラフにおける最大ステップ数
    {"recursion_limit": 150},
)
for s in events:
    print(s)
    print("----")
```
