https://www.dbdemos.ai/

Databricksのデモで使用するようなノートブックを簡単に入手することができます。

使い方は簡単です。Databricksノートブックで以下を実行してライブラリをインストールします。

```
%pip install dbdemos
```

デモの一覧を表示します。

```py:Python
import dbdemos
dbdemos.list_demos()
```
![Screenshot 2023-02-17 at 13.10.07.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1168882/18823f77-ede0-2cca-d2ca-9cb133d64940.png)


デモをインストールするには以下のようにデモを指定します。こちらはDelta Lakeのデモです。

```py:Python
dbdemos.install('delta-lake')
```

![Screenshot 2023-02-17 at 13.11.30.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1168882/1da8b384-9478-6b02-190e-303a9e6ed0ae.png)


上のコマンドを実行しているノートブックのパスにノートブックなどが追加されます。
![Screenshot 2023-02-17 at 13.12.22.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1168882/184e59e2-eef2-716a-152b-b147b5e3e11c.png)

追加されたノートブックを用いることでデモを体験することができます。これ以外にもCustomer360やMLOps、Unity Catalogのデモなどが取り揃えられています。
