# DatabricksとFierce Pharmaによる最近のサーベイでは、RWEプログラムの成功を妨げる、あるいは貢献するトップの要因を明らかにしました

ヘルスケア、ライフサイエンス業界においては、リアルワールドエビデンス(RWE)は、医療記録、画像、主訴にような臨床試験の外から収集されたデータから生成される医療証拠を指します。近年では、RWEは新たな治療のインパクト、安全性、効果に対する素晴らしい洞察をもたらす能力によって、多くの注目を集めています。実際、パンデミックの初期段階においては、ワクチンのロールアウトを加速する際に[RWEが重要](https://www.fiercehealthcare.com/tech/industry-voices-covid-19-vaccine-rollout-shows-real-world-evidence-was-ready-for-spotlight)となりました。

RWEの可能性に勇気づけられて、ヘルスエコシステムの組織はRWEに非常に大きな投資をおこなっています。しかし、大部分はリアルワールドデータの完全なメリットを提供する彼らの労力の妨げとなっている技術的課題に、いまだに苦戦しています。これらの課題を認識して、DatabricksとFierce Pharmaはさらに理解を深めるために100以上のバイオファーマのエグゼクティブにサーベイを実施しました。

- 何がRWEプログラムへの投資を推し進めているのか
- RWEプログラムの妨げ、貢献となるトップの要因
- ビジネス成果を解放するための理想的なデータアーキテクチャをどの様に構築するのか

このブログでは、[完全な研究レポート](https://www.databricks.com/p/whitepaper/realizing-the-value-of-real-world-evidence)と共に、彼らのRWEプログラムから多くの価値を導き出すための適切な技術的基盤とデータ戦略とをどの様に組み立てるのかに関する洞察を、医薬品メーカーのエグゼクティブ、リアルワールドエビデンスチーム、データプロフェッショナルの広範なエコシステムに提供することを狙いとしています。我々の発見のハイレベルなサマリーにダイブしていきましょう！

# リアルワールドエビデンスへの投資は止まるところを知りません

RWEの価値に関する議論は終わりました。ほぼすべての調査対象のエグゼクティブは、自分の企業でRWEプログラムに投資していると述べ、79%がそれらの投資に非常に強力にコミットしていると述べています。

これらの投資の背景に何があるのかに関して追加の質問をエグゼクティブに行いました。多くは、市場提供のスピードを加速することやシェアの拡大という点で共通していました。調査の一部では、Syneos HealthのエグゼクティブディレクターであるHarini Gopalakrishnanは「規制機関はこれまで以上に、企業が投資する最も大きな理由はリアルワールドデータであると考えることにオープンになっています。」[完全なレポート](https://www.databricks.com/p/whitepaper/realizing-the-value-of-real-world-evidence)では、投資のドライバー、最も重点が置かれている投資領域、リアルワールドデータの導入タイプについてより深い洞察を提供しています。

# RWEの投資は増加していますが、投資に見合っているのでしょうか？

サーベイから得られたキーとなる発見の一つは、おおむねRWEプログラムは成功しているということです。実際、10人のファーマエグゼクティブの9人は、彼らのRWE投資が膨大なビジネス成果をもたらしていると述べています。しかし、より深く見ていくと、プログラムの最高の成功とまあまあの成功の間のギャップが大きいことがわかりました。実際のところ、企業の9%のみが彼らのRWEプログラムは非常に成功したものだと考えていました。
![](https://cms.databricks.com/sites/default/files/inline-images/db-332-blog-img-1.png)

RWEに関するビジネス上に議論には勝ちましたが、企業が世界クラスのRWEプログラムを構築するには技術的障壁に対応し続けなくてはならないことを調査結果は示しています。

# RWE成功の障壁：全てはデータに起因します

それでは、何が妨げとなっているのでしょうか？我々の研究は、課題の大部分はRWEが大量のデータソースから生成されている事実に起因していることを明らかにしました。従来から、企業は統合されたエビデンスプランを構築するためには、データのサイロや障壁につながる数多くのデータセットを管理するために異なるプラットフォームに依存してきており、最終的にはチームが彼らのリアルワールドデータを活用することができていませんでした。トップの課題に関する詳細な発見は[レポート](https://www.databricks.com/p/whitepaper/realizing-the-value-of-real-world-evidence)を参照ください。

# だとしたら、どうすればRWEを成功させることができるのでしょうか？

プログラムの成功につながる要因についてエグゼクティブに質問しました。何人かは、人々の側面(RWEに対する強力なリーダーシップのサポート、内部のRWE専門性など)にフォーカスしましたが、大部分は彼らのビジョンを実行するためには適切な技術的ケイパビリティの必要性に関するものでした。

このフィードバックに基づいて、エグゼクティブとの議論は1つの質問に帰着しました：RWEのための理想的なデータプラットフォームを構築できるとしたら、何を優先度づけしますか？トップ5の回答がありました：すべてのデータに対する単一のプラットフォーム、AIと分析すべてに対する統合されたツールセット、データを容易に共有できる能力、強力なガバナンスとセキュリティ、オープンなデータスタンダードです(完全なリストは[レポート](https://www.databricks.com/p/whitepaper/realizing-the-value-of-real-world-evidence)を参照ください)。

これらの洞察によって、まあまあ成功したRWEプログラムからベストクラスのRWEプログラムに到達するための要因に光を当てることになりました。企業のこのジャーニーを助けるためには、これらの必要な能力のそれぞれに対応している[Databricksレイクハウス](https://qiita.com/taka_yayoi/items/438f762126f57868aa35)がギャップを縮めるものだと信じています。

[Delta Lake](https://www.databricks.com/jp/product/delta-lake-on-databricks)上に構築されたDatabricksレイクハウスプラットフォームによって、ヘルスケア、ライフサイエンス企業は、構造化された医療記録や非構造化の画像の様にすべてのリアルワールドデータを統合されたエビデンス生成のためにクラウドに格納できる様になります。データはベンダーロックインのないオープンなフォーマットで格納され、[Delta Sharing](https://www.databricks.com/jp/product/delta-sharing)を通じてパートナーと容易に共有することができます。

Databricksレイクハウスは、単一かつコラボレーティブな環境で分析と機械学習能力のフルセットを提供するので、バイオインフォマティシストから研究者、アナリストに至るすべてのペルソナは、リアルワールドデータを探索するために共に作業することができます。そして、[Unity Catalog](https://www.databricks.com/jp/product/unity-catalog)とHIPAAベースのセキュリティは、これらの能力をデータガバナンスとセキュリティで強化します。[Sanofiのような企業はレイクハウスを用いてRWEの価値を最大化し](https://www.youtube.com/watch?v=TduWqfLN0EE)、患者の人生を変える様な治療の提供に役立てています。
