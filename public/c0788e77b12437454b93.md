Databricks弥生です。ちょうど今日でDatabricksに入社してから5年が経ちました。本当にあっという間でした。

せっかくなので振り返りを行おうと思いましたが、つらつら文章を書くよりも、データ & AIカンパニーということでデータとAIで記事にしたいと思います。データはほぼ毎日書き続けた[Qiitaの記事](https://qiita.com/taka_yayoi)、そしてAIとしてDatabricksアシスタントの[データサイエンスエージェント](https://docs.databricks.com/aws/ja/notebooks/ds-agent)に分析、執筆してもらっています。アシスタントの指示ファイルは以下のようにしています。

```.assistant_instructions.md
- データ分析、生成AI、Databricksの専門家です
- 日本語で会話します
- 可視化にはplotlyを使います
```

QiitaのAPIで記事を取得して、Deltaテーブルに登録しています。

テキストを分析しやすくするために[AI関数](https://docs.databricks.com/aws/ja/large-language-models/ai-functions)を使って本文から要約を生成しています。

```sql
-- Step 1: Create a temporary view with the new summaries
CREATE OR REPLACE TEMP VIEW tmp_new_summaries AS
SELECT
  id,
  ai_query(
    'databricks-claude-sonnet-4-5',
    concat('次のDatabricks記事本文を日本語で200文字以内で要約してください。\n\n本文: ', body, '\n\n要約:')
  ) AS new_summary
FROM users.takaaki_yayoi.qiita_articles
WHERE summary IS NULL OR trim(summary) = '';

-- Step 2: Update the original table using the temporary view (use MERGE INTO for Databricks SQL)
MERGE INTO users.takaaki_yayoi.qiita_articles AS t
USING tmp_new_summaries AS v
ON t.id = v.id
WHEN MATCHED THEN
  UPDATE SET t.summary = v.new_summary;
```

以降は上のテーブルをコンテキストとして設定した上でのアシスタントとのやり取りです。以下の結果を見て自分でもいろいろな気付きがありました。やっぱり2023年の生成AI元年で書く内容がガラッと変わったなという実感はあります。

# 5年間のQiita記事振り返り分析

## 分析内容
1. 基本統計情報
2. 時系列分析(記事数、閲覧数、lgtm数の推移)

4. 要約からのトピック傾向分析
5. 総括

### 年別の主要キーワード分析

```py
import re
from collections import Counter

# キーワード抽出用の関数
def extract_keywords(text, top_n=15):
    # カタカナ、英単語、漢字2文字以上を抽出
    katakana = re.findall(r'[\u30a1-\u30f6\u30fc]{3,}', text)
    english = re.findall(r'\b[A-Z][a-zA-Z]{2,}\b', text)
    kanji = re.findall(r'[\u4e00-\u9faf]{2,}', text)
    
    # 除外キーワード
    exclude = {'こと', 'よう', 'ため', 'もの', 'これ', 'それ', 'あれ', 'どれ', 'この', 'その', 'あの', 'どの',
               'ここ', 'そこ', 'あそこ', 'どこ', 'いくつか', 'いくつ', 'いくつも', 'いくつかの',
               'すべて', '全て', '各々', 'それぞれ', 'それら', 'これら', 'あれら', 'どれら',
               '使用', '利用', '実装', '提供', '必要', '可能', '場合', '方法', '機能', '設定',
               '以上', '以下', '以外', '以内', '以降', '以前', '以後', '今回', '今年', '今月',
               '解説', '紹介', '確認', '説明', '記事', '内容', '情報', 'データ', 'コード',
               'The', 'This', 'That', 'These', 'Those', 'With', 'From', 'Into', 'About', 'After'}
    
    all_words = katakana + english + kanji
    filtered_words = [w for w in all_words if w not in exclude and len(w) >= 2]
    
    counter = Counter(filtered_words)
    return counter.most_common(top_n)

# 年別のキーワード抽出
yearly_keywords = {}
for _, row in yearly_summaries.iterrows():
    year = row['year']
    keywords = extract_keywords(row['all_summaries'])
    yearly_keywords[year] = keywords
    print(f"\n📅 {year}年 TOP 15 キーワード:")
    for i, (word, count) in enumerate(keywords, 1):
        print(f"  {i:2d}. {word:20s} ({count:3d}回)")
```
