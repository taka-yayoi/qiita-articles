こちらが興味深ったです。ちなみにn8nはnodemationだそうで。Claudeに聞きました。

https://qiita.com/taka_yayoi/items/7df1910959ba5b7dabc5

> n8nは「nodemation」の略です。これは開発者が「node」（ノード）と「automation」（自動化）を組み合わせて作った造語です。
>
> n8nという名前の由来は、"nodemaion"の最初と最後の「n」の間に8文字あることから来ています。これを短縮して「n8n」と表記しています（エヌ・エイト・エヌと読みます）。

サンプルはこちら。

https://github.com/tdosborne-databricks/slack-genie-n8n-integration

全部はまだ動かせてませんが、まずはDatabrikcs Appsでn8nを動かせることを初めて知ったので試してみます。思った以上に簡単に動きました。

# Databricks Appの作成

環境変数を定義する`app.yaml`を作成します。暗号化キーは設定していないのでコメントアウトしています。

```yaml:app.yaml
env:
# N8N configuration
- name: N8N_PORT
  value: '8000'
- name: N8N_HOST
  value: '0.0.0.0'
- name: N8N_COMMUNITY_PACKAGES_ALLOW_TOOL_USAGE
  value: 'true'
- name: DB_POSTGRESDB_SSL_REJECT_UNAUTHORIZED
  value: 'false'
#- name: N8N_ENCRYPTION_KEY
#  valueFrom: n8n-encryption-key
- name: N8N_REINSTALL_MISSING_PACKAGES
  value: 'true'
- name: N8N_COMMUNITY_PACKAGES_ENABLED
  value: 'true'
```

ライブラリをインストールするために`package.json`を作成します。Node.jsのパッケージ、初めてインストールします。

```json:package.json
{
  "name": "n8n-databricks-app",
  "version": "1.0.0",
  "description": "Run n8n as Databricks Apps",
  "main": "index.js",
  "dependencies": {
    "n8n": "^1.90.0"
  },
  "scripts": {
    "install-community-nodes": "mkdir -p ~/.n8n/nodes && cd ~/.n8n/nodes && npm i --legacy-peer-deps @mbakgun/n8n-nodes-slack-socket-mode n8n-nodes-databricks",
    "n8n": "n8n",
    "start": "npm run install-community-nodes && npm run n8n"
  }
}
```

これらは同じフォルダに格納しておきます。

設定ファイルは作成済みなので、**カスタムアプリ**で空のアプリを作ります。

設定画面で入力したのですが、うまくいかなかったのでメールの**Activate Licence Key**のURLアプリのURLで置き換えました。そのままクリックしても`http://0.0.0.0:8000/`にアクセスしてしまいます。

```
http://<アプリのURL>/settings/usage?key=<ライセンスキー>
```
