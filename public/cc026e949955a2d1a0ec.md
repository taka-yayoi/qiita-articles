# ドライバーノートブック

これはAIプレイグラウンドエクスポートによって自動生成されたノートブックです。同じフォルダーに3つのノートブックを生成しました：
- agent: エージェントを構築するコードが含まれています。
- config.yml: 設定が含まれています。
- **driver**: エージェントのログ、評価、登録、およびデプロイを行います。

このノートブックは、agentノートブックで定義されたエージェントをデプロイするためにMosaic AIエージェントフレームワーク（[AWS](https://docs.databricks.com/ja/generative-ai/retrieval-augmented-generation.html) | [Azure](https://learn.microsoft.com/ja-jp/azure/databricks/generative-ai/retrieval-augmented-generation)）を使用します。このノートブックは以下を行います：
1. エージェントをMLflowにログします
2. エージェントをUnity Catalogに登録します
3. エージェントをモデルサービングエンドポイントにデプロイします

## 前提条件

- このノートブックのすべての`TODO`を解決してください。
- [config.yml]($./config.yml)の内容を確認してください。これはエージェントが利用できるツールとLLMエンドポイントを定義しています。
- このフォルダーの[agent]($./agent)ノートブックを確認し、エージェントのコードを反復し、出力をテストしてください。

## config.yml

このエージェントでは、独自のエンべディングモデルとベクトル検索インデックスを使用しています。これをエージェントの設定に含めるように、以下のconfig.ymlでは`vector_search_index`と`embedding_endpoint`のエントリーを追加しています。

```yaml:config.yml
agent_prompt: "あなたはDatabricksに関する質問に回答するためにツールを活用する有能なアシスタントです。提供されているツールを活用してください: Databricksに関する質問に回答するために、vector_searchとgenerate_responseを活用してください。"
llm_endpoint: "taka-openai-gpt-4o-mini"
vector_search_index: "takaakiyayoi_catalog.qiita_2023.qiita_2023_vs"
embedding_endpoint: "taka-japanese-embedding"
tools:
  uc_functions:
    - "takaakiyayoi_catalog.qiita_2023.generate_response"
    - "takaakiyayoi_catalog.qiita_2023.vector_search"
```

## `agent`をMLflowモデルとしてログする
agentノートブックのコードをエージェントとしてログします。詳細は[MLflow - Models from Code](https://mlflow.org/docs/latest/models.html#models-from-code)を参照してください。

:::note info
**注意**
config.ymlで定義したカスタムのエンべディングモデルサービングエンドポイントとベクトル検索インデックスを`resources`に追加しています。これらの設定を行わないと、デプロイされたエージェントからそれらのリソースにアクセスする際に、`[REMOTE_FUNCTION_HTTP_FAILED_ERROR] The remote HTTP request failed with code 403, and error message 'HTTP request failed with status: {"error_code":"PERMISSION_DENIED","message":"Insufficient permissions for UC entity `と言うような権限不足のエラーが発生します。
:::


```py
# モデルをMLflowにログする
import os
import mlflow

from mlflow.models import ModelConfig
from mlflow.models.signature import ModelSignature
from mlflow.models.rag_signatures import (
    ChatCompletionRequest,
    ChatCompletionResponse,
)
from mlflow.models.resources import (
    DatabricksFunction,
    DatabricksServingEndpoint,
    DatabricksVectorSearchIndex
)
from databricks.sdk import WorkspaceClient

w = WorkspaceClient()
config = ModelConfig(development_config="config.yml")
resources = [
    DatabricksServingEndpoint(endpoint_name=config.get("llm_endpoint")),
    DatabricksServingEndpoint(endpoint_name=config.get("embedding_endpoint")),
    DatabricksVectorSearchIndex(index_name=config.get("vector_search_index")),
]
uc_functions_to_expand = config.get("tools").get("uc_functions")
for func in uc_functions_to_expand:
    # 関数名が正規表現の場合、スキーマ内のすべての関数を取得
    if func.endswith("*"):
        catalog, schema, _ = func.split(".")
        expanded_functions = list(
            w.functions.list(catalog_name=catalog, schema_name=schema)
        )
        for expanded_function in expanded_functions:
            resources.append(
                DatabricksFunction(function_name=expanded_function.full_name)
            )
    # それ以外の場合は関数を追加
    else:
        resources.append(DatabricksFunction(function_name=func))

signature = ModelSignature(ChatCompletionRequest(), ChatCompletionResponse())

input_example = {
    "messages": [{"role": "user", "content": "find me franchises in the US"}]
}

with mlflow.start_run():
    logged_agent_info = mlflow.pyfunc.log_model(
        "agent",
        python_model=os.path.join(
            os.getcwd(),
            "agent",
        ),
        signature=signature,
        input_example=input_example,
        model_config="config.yml",
        resources=resources,
    )
```

## モデルをUnity Catalogに登録

以下の`catalog`、`schema`、`model_name`を更新して、MLflowモデルをUnity Catalogに登録します。

```py
mlflow.set_registry_uri("databricks-uc")

# TODO: UCモデルのカタログ、スキーマ、およびモデル名を定義します
catalog = "takaakiyayoi_catalog"
schema = "qiita_2023"
model_name = "databricks_rag"
UC_MODEL_NAME = f"{catalog}.{schema}.{model_name}"

# モデルをUCに登録します
uc_registered_model_info = mlflow.register_model(model_uri=logged_agent_info.model_uri, name=UC_MODEL_NAME)
```
