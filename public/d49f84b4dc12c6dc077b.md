# 新たに検証されたインテグレーションによって、レイクハウスのデータの取り込み、解析、信頼性の確保が容易になります。

Databricks [Partner Connect](https://databricks.com/jp/partnerconnect)に新たに6つのインテグレーションが追加されたことを発表できて嬉しく思っています。パートナーシップを拡大することで、ユーザーの皆さまはDatabricksレイクハウスプラットフォームに最新のデータを組み込むことができ、大規模な診療、生物医学テキストを処理するために事前構築済みディープラーニングを使用でき、分析、データサイエンスコラボレーションのための最先端のノートブックを用い、自動でデータ品質を追跡し、改善することができます。これは、最も検証されたデータ、そして、分析、AIツールを検索、テスト、Databricksへの組み込みを行うワンストップのポータルであるPartner Connectを通じて、お客さまに世界最高のパートナーを提供するというコミットメントの一部です。

この四半期で、我々はPartner Connectに以下のパートナーインテグレーションを追加しました。

# データ取り込み

**Arcion**
[Arcion](https://www.arcion.io/partners/databricks)は、Oracle、Oracle Exadata、Oracle RAC、IBM DB2、Microsoft SQL Serverのようなリレーショナルデータベース、SalesforceのようなSaaSアプリケーションのデータをDatabricks上のDelta Lakeに連携するクラウドネイティブ、チェンジデータキャプチャーベースのデータリプリケーションプラットフォームです。Arcionはトランザクションの完全性、原子的なスキーマ変換、ゼロレーテンシーを提供します。これによって、例えば、クリックストリームデータ、カスタマー360、脅威からの防御など、リアルタイムかつ最新のデータからメリットを得ることができるビジネスクリティカルな分析、AIワークロードに対する理想的なソリューションを実現することができます。また、Arcionは[Databricksベンチャーズのポートフォリオにおける最初のゼロコードデータモビリティプラットフォーム](https://databricks.com/blog/2022/02/17/databricks-ventures-invests-in-arcion-to-enable-real-time-data-sync-with-the-lakehouse.html)の一つとなっています。デモを参照するには[こちら](https://youtu.be/OT9uPBKMZWA)をクリックしてください。

# データ変換

**Matillion**
Databricksにおける[Matillion ETL for Delta Lake](https://www.matillion.com/technology/lakehouse/databricks/)はレイクハウスアーキテクチャにノーコード/ローコードのデータインテグレーションを提供します。さまざまなビジネスのユーザーは、自身のデータのオーナーシップを持つことができ、Delta Lakeによって下支えされることで、オンデマンドの機械学習、迅速なレポート、BIの改善を実現するために、Matillion ETLのベストクラスのデータ変換機能を活用することができます。Partner Connectで利用できるようになることで、ユーザーは事前の設定なしに、オペレーショナルデータベース、ファイル、NoSQL、APIのソースからビジネスクリティカルなデータを容易にDelta Lakeに抽出、ロードすることが可能となります。

# 人工知能、機械学習

**John Snow Labs**
過去数年をかけて、[John Snow Labs](https://www.johnsnowlabs.com/databricks/)は、ヘルスケア、ライフサイエンス企業が大規模な非構造化テキストデータを患者に対する洞察に変換するのを支援するために、Databricks上での実行に最適化されたソリューションを開発してきました。キーとなるユースケースには、[薬害イベントの検知](https://databricks.com/solutions/accelerators/adverse-drug-event-detection)、[オンコロジーの洞察の抽出](https://databricks.com/solutions/accelerators/nlp-oncology)、PHI削除の自動化などが含まれます。Partner Connectによって、ベストオブブリード、かつ最も広く活用されているNLPライブラリであるSpark NLP for Healthcareを容易に活用することができます。これによって、ヘルスケア機関は、分析やデータサイエンスのために、大規模な診療、生物化学テキストデータを、単一かつ高性能なレイクハウスプラットフォームで統合することができます。

**Hex**
[DatabricksとHex](https://hex.tech/integrations/databricks)は共に、次世代分析を支援しています。Databricksは比類なきデータ処理能力とストレージを提供し、Hexはデータをデータサイエンスのデータ探索や分析に使えるようにします。HexはシンプルかつセキュアにDatabricksレイクハウスに接続できるので、ユーザーはコラボレーティブなSQL、Pythonノートブックで構造化データ、非構造化データに対してクエリーを行うことができ、誰でも使用できるインタラクティブなデータアプリケーションとして、成果を共有することができます。Hexはデータによって裏打ちされた意思決定を行えるように、いかなるスキルセットのユーザーも支援します。HexとDatabricksがどのようにシームレスに動作するのかを知りたいのであれば、[こちら](https://hex.tech/integrations/databricks)を参照いただくかフリー[トライアル](https://app.hex.tech/)にサインアップしてください。


# データ品質

**Anomalo**
Anomaloは、データの問題を自動的に検知、根本原因を理解し、DatabricksレイクハウスでBI、分析、機械学習フレームワークを活用する前に、お使いのデータの品質を信頼できることを保証します。データ品質に対する従来のルールベースのアプローチとは異なり、Anomaloは機械学習を用いた自動チェックを提供します。問題が検知されると、Anomaloは問題の原因と考えられるポイントを示す即興の根本原因分析と、文脈を伝えるための豊富なビジュアライゼーションセットを提供します。これは、ユーザーがデータに対する問題を調査、火消しする時間に費やす時間が削減され、データドリブンの意思決定に多くの時間を費やせることを意味します。Anomaloの詳細を知りたいのであれば、[Anomalo\.com](http://anomalo.com/)を訪れるか、[デモ](https://www.anomalo.com/requestademo)をリクエストしてください。

**Lightup**
Lightupは、データドリブンの企業が容易に迅速かつ継続的なデータ品質のチェックを正確かつ包括的に行えることを支援します。Databricksプラットフォームとの密なインテグレーションによって、Lightupはレイクハウスに対してデータ信頼性に関する追加のレイヤーを提供し、企業はその場でデータ品質チェックを行い、すべてクリックの操作で、レガシーなビッグデータシステムからDatabricksへのデータ移行を加速します。すぐにレイクハウスのデータ品質の最適化を始めましょう！Lightupの詳細については、[lightup\.ai](http://lightup.ai/)を訪れてください。

# お客さまにスポットライト：Aktifyによるデータリテラシーの実現

Partner Connectは、みなさまの分析、AIユースケースをサポートするために、パートナーツールを探し出し、セキュアにDatabricksに接続する手間を排除します。例えば、会話型AIを提供している[Aktify](https://aktify.com/)では、堅牢な機械学習を用いて、会話を支援することでお客様を喜ばせるというミッションを持っています。Partner ConnectでTableauコネクターをワンクリックするだけで、Aktifyのすべてのユーザーはデータエンジニアの支援を待つことなしに、キーとなるビジネスの疑問に答えるために、自身のTableauダッシュボードを立ち上げることができます。このため、今ではAktifyにはコラボレーションを通じて高付加価値のタスクにフォーカスし、シームレスにデータの洞察を共有するデータプロフェッショナルが2ダース以上存在しています。

> 「(85G相当のオペレーショナルデータを含む)すべてのデータがDatabricksレイクハウスですぐに利用できるので、もはや我々はSnowflakeにデータをステージングしていません」、AktifyのDirector of Data & AnalyticsであるBrandon Smithはこう言います。「また、Partner Connectはチームが新たなデータ&AIソリューションを見つけ出すことを支援してくれ、我々の企業全体におけるデータリテラシーの実現を後押ししてくれています。」
