# AI Builderとは

[マニュアル](https://docs.databricks.com/aws/ja/generative-ai/ai-builder/#ai-builder-%E3%81%A8%E3%81%AF)にも記載がありますが、あるユースケース向けのAIエージェントを構築、最適化できるノーコードソリューションです。

# AI Builderのウォークスルー

ベータ版時点では**情報抽出**のみがサポートされています。構造化されていないテキストから指定された情報を抽出するエージェントを構築することができます。

https://docs.databricks.com/aws/ja/generative-ai/ai-builder/key-info-extraction

## 準備

使うには以下の準備が必要です。

- 情報を抽出するファイル。サポートされている形式は[こちら](https://docs.databricks.com/aws/ja/generative-ai/ai-builder/key-info-extraction#%E3%82%B5%E3%83%9D%E3%83%BC%E3%83%88%E3%81%95%E3%82%8C%E3%81%A6%E3%81%84%E3%82%8B%E3%83%87%E3%83%BC%E3%82%BF%E5%BD%A2%E5%BC%8F)。今回は自分のQiita記事をAPIで取得して、マークダウン形式でボリュームに保存しています。

## エージェントの利用

エージェントはモデルサービングエンドポイントにデプロイされるので、[ai_query](https://docs.databricks.com/gcp/ja/large-language-models/ai-functions#-%E6%B1%8E%E7%94%A8%E6%A9%9F%E8%83%BD-ai_query)などから利用できます。

```sql
%sql
WITH query_results AS (
  SELECT
    value AS input,
    ai_query(
      'qiita-info-extractor',
      input,
      failOnError => false
    ) AS response
  FROM (
    SELECT value
    FROM read_files('/Volumes/taka_yayoi_catalog/ai_builder/articles/', wholeText => true, format => 'text')  -- Customize the path to your text corpus
    LIMIT 20
  )
)
SELECT
  input,
  response.result AS response,
  response.errorMessage AS error
FROM query_results
```
