このセクションにはプロンプトに関する全てが含まれています。プロンプトは、言語モデルに引き渡される値です。この値は、(LLM向けの)文字列あるいは(チャットモデル向けの)メッセージのリストとなります。これらのプロンプトのデータタイプは比較的シンプルですが、それらの構築はそうではありません。ここでのLangChainの訴求価値には以下があります:

- 文字列のプロンプトとメッセージプロンプトの標準的インタフェース
- 文字列プロンプトテンプレートとメッセージプロンプトテンプレートの(使い始めるための)標準的なインタフェース
- サンプルセレクター: 言語モデルが従うプロンプトにサンプルを挿入する手法
- 出力パーサー: 言語モデルが情報を出力するフォーマットとしてプロんtぷとに対する指示を埋め込む手法と、出力文字列をフォーマットにパースする手法

文字列プロンプト固有のタイプ、チャットプロンプト固有のタイプ、サンプルセレクター、出力パーサーに関する詳細なドキュメントがあります。

ここでは、シンプルなプロンプトを用いて使い始める際の標準インタフフェースのクイックスタートをカバーします。

# PromptTemplates

PromptTemplatesはプロンプトの値を構築することに責任を持ちます。これらのPromptTemplatesはフォーマッティング、サンプル選択などを行うことができます。ハイレベルでは、これらは基本的にはプロンプトを構築するための`format_prompt`を公開するオブジェクトです。内部では**いろいろなこと**が行われます。

```py
from langchain.prompts import PromptTemplate, ChatPromptTemplate
```

```py
string_prompt = PromptTemplate.from_template("tell me a joke about {subject}")
```

```py
chat_prompt = ChatPromptTemplate.from_template("tell me a joke about {subject}")
```

```py
string_prompt_value = string_prompt.format_prompt(subject="soccer")
```

```py
chat_prompt_value = chat_prompt.format_prompt(subject="soccer")
```

# `to_string`

これは、(生のテキストを期待する)LLMに値を渡す際に呼び出されます。

```py
string_prompt_value.to_string()
```
```
'tell me a joke about soccer'
```

```py
chat_prompt_value.to_string()
```
```
'Human: tell me a joke about soccer'
```

# `to_messages`

これは、(メッセージのリストを期待する)チャットモデルに値を渡す際に呼び出されます。

```py
string_prompt_value.to_messages()
```
```
[HumanMessage(content='tell me a joke about soccer', additional_kwargs={}, example=False)]
```

```py
chat_prompt_value.to_messages()
```
```
[HumanMessage(content='tell me a joke about soccer', additional_kwargs={}, example=False)]
```
