SQLクエリーのサンプルを追加することで、Genieの能力をより高めることができます。

[こちら](https://qiita.com/taka_yayoi/items/fa16e38bcc1ff68ba515)でも紹介したように、AI関数を含むSQLクエリーを追加することで、Genieは予測までも行ってくれるようになります。

```sql
WITH
aggregated AS (
  SELECT
    DATE(tpep_pickup_datetime) AS ds,
    SUM(fare_amount) AS revenue
  FROM
    samples.nyctaxi.trips
  GROUP BY
    1
)
SELECT * FROM AI_FORECAST(
  TABLE(aggregated),
  horizon => '2016-03-31',
  time_col => 'ds',
  value_col => 'revenue'
)
```
