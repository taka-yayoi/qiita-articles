ノートブックの実装はDatabricksとJupyterLabでも異なるので、別のアプローチが必要となります。

ここでは、[ipycanvas](https://ipycanvas.readthedocs.io/en/latest/)を使います。

```py
%pip install ipycanvas
```

次のセルに以下のロジックを記述します。

```py
from math import pi
from ipycanvas import Canvas
width= 515
height= 474
canvas = Canvas(width=width, height=height)
display(canvas)
```

この時点ではキャンバスには何も表示されません。

次のセルに以下の内容を記述します。

:::note
**注意**
必ずセルを分けるようにしてください。同じセルに記述すると動作しません。
:::

```py
from ipywidgets import Image
img = Image.from_url("https://apod.nasa.gov/apod/image/2208/Cartwheel_Webb_2000.jpg")

canvas.draw_image(img, 0, 0)

from ipywidgets import Output
out = Output()

coordinates = []

@out.capture()
def handle_mouse_down(x, y):
  global coordinates
  coordinates.append((x,y))
  canvas.fill_style = "red"
  canvas.fill_arc(x, y, 10, 0, 2*pi)
  print("Mouse down event:", x, y)

canvas.on_mouse_down(handle_mouse_down)
```

キャンバスに画像が表示されます。
![Screenshot 2023-09-13 at 15.59.42.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1168882/664a395b-4e17-10bc-b663-9d179a807d33.png)

画像をクリックするとクリックした場所に赤丸が表示されます。
![Screenshot 2023-09-13 at 16.04.41.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1168882/80fe5189-1442-22f3-a921-290a3d246950.png)

変数`coordinates`にアクセスするとクリックされた座標にアクセスすることができます。

```
Out[4]: [(202, 164), (345, 294), (124, 300), (320, 192)]
```
