# はじめに

2026年6月15〜18日、サンフランシスコのMoscone Centerで**Data + AI Summit (DAIS) 2026**が開催されます。Databricksが主催するデータとAI領域で世界最大級のカンファレンスです。

「現地には行けないけど、最新情報はキャッチアップしたい...」という方に朗報です。**バーチャル体験（Virtual Experience）が無料で提供されます。**

この記事では、バーチャル参加で何が視聴できるのか、スケジュールや注目ポイントをまとめます。

# バーチャル体験の概要

| 項目 | 内容 |
|------|------|
| **配信日（日本時間）** | 2026年6月17日（水）・18日（木） |
| **参加費** | **無料** |
| **キーノート（生配信）** | 日本時間 深夜（現地午前中） |
| **キーノート（再配信）** | 日本時間 13:00〜 **日本語同時通訳音声付き** |
| **セッション** | セレクトされたセッションをオンデマンドで視聴可能 |

# 無料バーチャルパスに含まれるもの

- **キーノートのライブ配信** ― Databricksの最新イノベーション、ライブデモ、業界リーダーとの対話
- **セレクトセッションのオンデマンド視聴** ― 800以上のセッションから厳選されたコンテンツ
- **Summit Live** ― 専門家によるリアルタイム解説番組
- **オンライントレーニング** ― 学習コンテンツへのアクセス

# セッションのテーマ領域

800以上のセッションが以下のテーマで構成されています。バーチャルではこの中からセレクトされたセッションが配信されます。

- **AI & エージェント** ― エンタープライズAI、AIエージェントの構築と運用
- **データエンジニアリング** ― Lakehouse アーキテクチャ、ETLパイプライン
- **データウェアハウジング** ― SQL分析、パフォーマンス最適化
- **ガバナンス・セキュリティ** ― Unity Catalog、データガバナンス
- **分析・BI** ― ダッシュボード、生成AIを活用した分析
- **アプリケーション開発** ― Databricks Apps、DevOps
- **オープンソース** ― Apache Spark、Delta Lake、MLflow

## バーチャル配信が確認されているセッション例

- **Agent Ready Data Governance** ― AIエージェント時代に求められるデータガバナンス
