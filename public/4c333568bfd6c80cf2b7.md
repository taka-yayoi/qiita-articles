これは嬉しいエンハンス。

https://docs.databricks.com/ja/workflows/jobs/conditional-tasks.html#add-branching-logic-to-your-job-with-the-ifelse-condition-task

これまでにも、依存するタスクの成功・失敗に基づいて判断を行う [`Run if`の判定機能](https://qiita.com/taka_yayoi/items/0dd9a25629c3464e36ac#databricks%E3%82%B8%E3%83%A7%E3%83%96%E3%81%A7%E6%9D%A1%E4%BB%B6%E4%BB%98%E3%81%8D%E3%81%A7%E3%82%BF%E3%82%B9%E3%82%AF%E3%82%92%E5%AE%9F%E8%A1%8C%E3%81%99%E3%82%8B)がありましたが、これにさらに機能が追加される形になります。[ジョブやタスクのパラメーター変数](https://docs.databricks.com/ja/workflows/jobs/parameter-value-references.html)や[タスクバリュー](https://docs.databricks.com/ja/workflows/jobs/share-task-context.html)に基づいて処理を切り替えることができます。

https://docs.databricks.com/ja/workflows/jobs/conditional-tasks.html#run-if-condition-options

早速動かしてみます。

# ノートブックの準備

ノートブックを3つ用意します。

最初のノートブックではタスクバリュー`gender`に値を設定します。

```py:start
dbutils.jobs.taskValues.set(key = 'gender', value = 'Male')
```

タスクバリューの値に応じて呼び出されるノートブックを二つ用意します。

```py:male
print("男性です")
```

```py:female
print("女性です")
```

# ジョブの設定

ジョブを構成します。最初のノートブックをタスクとして追加します。
![Screenshot 2023-11-03 at 17.14.23.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1168882/cbced428-43f9-e551-774f-c4dd47ded335.png)

タスクを追加して、一番下に表示される`if/else condition`を選択します。
![Screenshot 2023-11-03 at 17.14.38.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1168882/af4e6a98-1c0d-e269-679b-ff7eee53fc2e.png)
