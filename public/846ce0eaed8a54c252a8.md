# 統合ナビゲーションへのオプトイン

統合ナビゲーションにオプトインするには、以下を行います:

1. ワークスペースのサイドバーで、**Enable New UI**をクリックします。
1. **Try the new navigation UI**ダイアログで**Enable**をクリックします。

# ホームページ

ワークスペースホームページの以下のセクションは、皆様がDatabricksレイクハウスにオンボードし、ナビゲーションする支援をするために、一般的なタスクやワークスペースオブジェクトへのショートカットを提供します:

**Get started**

このセクションは、製品領域における以下の一般的なタスクへのショートカットを提供します:

- アップロードデータ UIによるデータのインポート
- ノートブックの作成
- クエリーの作成
- AutoML experimentの設定

:::note info
**注意**
ホームページに表示されるタイルは、あなたに割り当てられている[エンタイトルメント](https://docs.databricks.com/administration-guide/users-groups/index.html#assigning-entitlements)に依存します。
:::

**Recents**

このセクションには、ファイル、ノートブック、エクスペリメント、クエリー、ダッシュボード、アラートを含む製品領域において最近参照したワークスペースオブジェクトが表示されます。

**Popular**

このセクションには、ファイル、ノートブック、エクスペリメント、クエリー、ダッシュボード、アラートを含む製品領域において過去30日間でもっともユーザーとのインタラクションがあったオブジェクトが表示されます。

# フルページのワークスペースブラウザ

ワークスペースブラウザは、フルページのエクスペリメントと、ノートブックから移動することなしにワークスペースコンテンツを参照できるコンテキストベースのブラウザを提供します。
![](https://docs.databricks.com/_images/contextual-browser.png)

# 検索

ノートブック、ダッシュボード、アラート、ファイル、フォルダー、ライブラリ、Unity Catalogに登録されているテーブル、ジョブ、リポジトリのようなワークスペースオブジェクトを一つの場所から検索するために、トップバーを使用します。また、検索バーから最近参照したオブジェクトにもアクセスすることができます。

# ワークスペース管理者設定、ユーザー設定

ワークスペース管理者とワークスペースユーザーの設定はセイン領域全てで統合されています。管理者ユーザー、非管理者ユーザーに対して統合されたエクスペリエンスを提供するために、SQL設定は一般的な設定に統合されています。

すべてのワークスペース管理者設定には、以下のタブを含む**Admin Settings**からアクセスすることができます:

- SQL settings
- External data sources
- SQL warehouse settings

すべてのワークスペースユーザー設定には、以下のタブを含む**User Settings**からアクセスできます:

- **Password**タブは**Account & Password**タブに表示されます。
- **Query snippets**タブは、Databricks SQLエンタイトルメントを持つユーザーに表示されます。
