# _cache()_ の使用

いくつかのカラムを持つ大規模データセットを作成します。

```py
from pyspark.sql.functions import col

df = spark.range(1 * 10000000).toDF("id").withColumn("square", col("id") * col("id"))
df.cache().count()
```
```
10000000
```

どこにデータが格納されるのかを確認するためにSpark UIのstorageタブをチェックします。
![Screenshot 2024-03-27 at 17.02.51.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1168882/3a88185e-568e-7f29-266f-8b9e47825159.png)

`Disk Memory Deserialized 1x Replicated`となっています。

```py
df.unpersist() # unpersistしない場合、下のdf2はdfと同じクエリープランであるためdf2はキャッシュされません
```
![Screenshot 2024-03-27 at 17.04.54.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1168882/c6cf3345-0ce4-12dc-d8d5-1c686b1f97e5.png)

# _persist(StorageLevel.Level)_ の使用

```py
from pyspark import StorageLevel

df2 = spark.range(1 * 10000000).toDF("id").withColumn("square", col("id") * col("id"))
df2.persist(StorageLevel.DISK_ONLY).count()
```
```py
df2.count()
```
```
10000000
```

データがどこに格納されているのかを確認するためにSpark UIのStorageタブをチェックします。

![Screenshot 2024-03-27 at 17.07.48.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1168882/3da5a4d7-d16e-e7dc-7b14-d69a6b0b2830.png)

`Disk Deserialized 1x Replicated`となっています。

# SQLでのキャッシュ

```py
df.createOrReplaceTempView("dfTable")
spark.sql("CACHE TABLE dfTable")
```

どこにデータが格納されるのかを確認するためにSpark UIのstorageタブをチェックします。
![Screenshot 2024-03-27 at 17.11.58.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1168882/d6b58cba-0b38-34be-3e7c-a9be4a3c7f57.png)

`In-memory table dfTable`がキャッシュされています。

```py
spark.sql("SELECT count(*) FROM dfTable").show()
```
```
+--------+
|count(1)|
+--------+
|10000000|
+--------+
```
