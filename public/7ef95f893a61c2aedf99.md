# 要件

- Pythonノートブック
- Databricks Runtimeバージョン 13.3 LTS 以降。
- アクセスモードは、**シングル ユーザー**(割り当て済み) または **[分離共有なし]** である必要があります。

# 設定

**[実験的な機能]** セクションで、**[Python ノートブック インタラクティブ デバッガー]** をオンにします。

![Screenshot 2024-03-28 at 9.46.47.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1168882/c26ae5ae-665c-661e-7eba-644a7bc07e54.png)

# ウォークスルー

DatabricksランタイムML 15.0のクラスターを使います。以下のロジックを記述します。

```py
def foo(df):
  print(df)
```
```py
import time
import pandas as pd

d = {"col1": [1, 2], "col2": [3, 4]}
df = pd.DataFrame(data=d)
x = 5
time.sleep(6)
x = 6
print("pre foo")
foo(df)
print("done!")
```

## デバッガの起動

1つ目のセルを実行し、2つ目のセルを実行する際に**セルをデバッグ**を選択します。
