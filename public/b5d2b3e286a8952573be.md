Claude Code普段使いの自分にとってはこれは嬉しい。

**モデルサービング**のページにアクセスすると、見慣れない**コーディングエージェントを統合**のパネルが。

![Screenshot 2025-10-21 at 11.28.05.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1168882/62ce15e8-d62e-496e-9b02-894d0ed1b92b.png)

**Get Started**をクリックすると右側にパネルが開きます。
![Screenshot 2025-10-21 at 11.28.35.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1168882/dcf6cc63-3df2-4f8d-b49c-b4f1afd0d985.png)

なお、設定には[パーソナルアクセストークン](https://docs.databricks.com/aws/ja/dev-tools/auth/pat#gsc.tab=0)が必要です。
![Screenshot 2025-10-21 at 11.49.16.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1168882/2de77b07-9de2-4eff-ac08-fb1b8ba45f07.png)

デフォルトのモデルを選択します。設定に応じて下の`~/.claude/settings.json`が更新されますのでコピーします。
![Screenshot 2025-10-21 at 11.29.00.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1168882/eb15868d-7016-4140-a13a-a5ab27f93c88.png)



[Claude Codeのマニュアル](https://docs.claude.com/en/docs/claude-code/settings)に従って、ローカルマシンで`~/.claude/settings.json`を編集します。私は以下ような設定にしています。

```json:~/.claude/settings.json
{
  "env": {
        "ANTHROPIC_MODEL": "databricks-claude-sonnet-4-5",
        "ANTHROPIC_BASE_URL": "https://xxxxx.cloud.databricks.com/serving-endpoints/anthropic",
        "ANTHROPIC_AUTH_TOKEN": "<Databricksパーソナルアクセストークン>",
        "ANTHROPIC_DEFAULT_OPUS_MODEL": "databricks-claude-opus-4-1"
  },
  "hooks": {
    "Notification": [
      {
        "matcher": "",
        "hooks": [
          {
            "type": "command",
            "command": "/usr/bin/afplay /System/Library/Sounds/Glass.aiff"
          }
        ]
      }
    ]
  }
}
```

Claude Codeを起動します。

```sh
claude
```

おおー、Databricks上の`databricks-claude-sonnet-4-5`が表示されています。
![Screenshot 2025-10-21 at 11.40.06.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1168882/8db545e7-b33e-4302-855a-d389374d99d5.png)

念のため質問してみます。
![Screenshot 2025-10-21 at 11.41.37.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1168882/b0809bde-d6b1-45b4-9ae6-cdf852eac06b.png)

さらにシステムテーブルでも確認してみます。

```sql
SELECT 
  eu.*,
  convert_timezone('UTC', 'Asia/Tokyo', eu.request_time) AS request_time_jst,
  se.endpoint_name 
FROM system.serving.endpoint_usage eu
JOIN system.serving.served_entities se
  ON eu.served_entity_id = se.served_entity_id
WHERE eu.requester = "takaaki.yayoi@databricks.com"
ORDER BY eu.request_time DESC
LIMIT 10
```

呼び出されてますね。
![Screenshot 2025-10-21 at 12.00.10.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1168882/a513c9a1-60b8-4e44-9d2d-34ae3d217382.png)

上はClaude Codeの設定例ですが、多分Cursorとかでもいけるのではないでしょうか。
