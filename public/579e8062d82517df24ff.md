# Teradata、Snowflake、Redshift、Oracle、NetezzaなどからDatabricks SQLへの移行をシンプルに

:::note info
**サマリー**
- Teradata、Snowflake、Amazon Redshift、Microsoft SQL Serverを含むデータウェアハウスの意向をシンプルにし加速するために、DatabricksはBradeBridgeを歓迎します。
- AIを活用した高度な変換と設定ドリブンのアプローチを組み合わせることで、データプラットフォーム移行の劇的にコストを削減し、リスクを低減します。
- Databricksのパートナーとお客様は、BladeBridgeとその他の移行ツールを自由に利用できるようになります。
:::

Databricksは、エンタープライズデータウェアハウスのために立証されたAI活用移行ソリューションであるBladeBridgeを歓迎します。DatabricksとBladeBridgeはともに、Oracle、SQL Server、Snowflake、Redshiftのようなレガシーなデータウェアハウスを、Databricksがカテゴリーを定義したレイクハウスの上に構築されたデータウェアハウスである[Databricks SQL](https://www.databricks.com/jp/product/databricks-sql)(DBSQL)への移行に必要な企業の作業を加速することを手助けします。BladeBridgeは、利用者に変換のスコープに対する明確な洞察、コードのトランスパイル、LLMを活用した変換、移行されるシステムの容易な検証を提供します。

5年前、我々はレイクハウスアーキテクチャのビジョンを実現するためにDatabricks SQLを開発し、データウェアハウスにデータレイクのスケーラビリティと効率性をもたらしました。それ以来、業界はDatabricks SQLを明確なリーダーとして、未来のデータアーキテクチャとしてレイクハウスを受け入れてきました。すでに世界中の10,000以上の企業は、レガシーなソリューションでは提供できなかった[世界記録のパフォーマンス](https://www.databricks.com/jp/blog/2021/11/02/databricks-sets-official-data-warehousing-performance-record.html)、[9倍の効率性](https://www.databricks.com/jp/blog/databricks-sql-year-review-part-i-ai-optimized-performance-and-serverless-compute)やシンプルさを提供するためにDatabricks SQLを導入しています。また、さらに自然言語の機能や予測的最適化の機能を提供するために、Databricks SQL全体にAIを組み込むことを継続しています。現在、Databricks SQLはPower BI、Tableau、dbtのようなツールを支援しており、$600Mの経常利益をもたらすDatabricksの歴史においてもっとも高速に成長している製品として確固たる地位を築いています。

また、アナリストは市場のリーダーとしてDatabricksを認知しています。例えば、Fosterは[The Forrester Wave™: Data Lakehouses, Q2 2024](https://www.databricks.com/jp/blog/databricks-named-leader-2024-forrester-wave-data-lakehouses)の現行のオファリングと戦略のカテゴリーの両方でDatabricksをリーダーとして認めています。
![](https://www.databricks.com/sites/default/files/inline-images/forrester-wave-databricks.png?v=1738273363)

すでにBladeBridgeは、数百の顧客において立証されたデプロイメントでAccenture、Capgemini、Celebal Technologies、Tredenceのようなシステムインテグレーターにおいて鍵となるテクノロジープロバイダーとなっています。そして、すべてのお客様はデータウェアハウスの歴史を定義してきたプロプライエタリ、高価、サイロ化されたプラットフォームをモダナイズすることで、自分たちのデータインフラストラクチャを取り戻すことで、劇的にコストを削減し、リスクを低減することが可能となります。

# BradeBridgeとは？

BladeBridgeは、Teradata、Oracle、Snowflake、SQL Server、Amazon Redshift、Azure Synapse Analytics、Hiveを含む20以上のレガシーなデータウェアハスやETLツールを、従来のアプローチよりも50%高速な方法で移行するAIを活用したアプローチを提供します。

![](https://www.databricks.com/sites/default/files/inline-images/data-warehouses.jpg?v=1738273363)
*あるケースにおいては、上でリストしている複数の派生系がBladeBridgeでサポートされています。*

BladeBridgeは、たった数時間ですべてのETLとデータベースの資産のサマリーを自動的に構築することでお客様の数ヶ月の取り組みを削減し、移行のスコープと複雑性に関する完全なレポートを提供します。さらに、レガシーシステムとDatabricks SQLの間での自動クエリーテストによって、変換プロセスにおけるクイックな修正を行えるように早期に矛盾を特定します。

次に、システム間の変換ではレガシーなアーキテクチャとDatabricks SQL間の相違を容易に考慮できる設定ドリブンのアプローチを採用しています。重要なこととして、このアプローチによってお客様は変換パターンに対する完全なオーナーシップを維持できるので、以降の後半のステージで新たな要件が発生した場合にはいつでも設定を更新することができます。

BladeBridgeのAIドリブンの変換では、すべてのレガシーETL、SQL、そのほかのコードを考慮します。どれかのコンポーネントでユニットテストに失敗すると、問題を解決するために設定ファイルはシンプルに適応します。これによって、変換の大部分は設定の指示のみで対応できるようになる迅速で繰り返しのプロセスを提供します。

# Databricksへのクイックで効率的な移行によって立証された企業の成功

Thomas Internationalの高価なSnowflakeの環境ではリアルタイムデータを取り扱うことができず、SQLのみサポートしていました。[彼らのデータ戦略に対する野心を実現](https://medium.com/@luket_35341/unlocking-our-data-strategy-at-thomas-with-databricks-50db38c209dd)するために、彼らはデータサイエンティストがPythonとRにおけるスキルを活用できるようにするスケーラブルな環境を必要としていました。DatabricksはThomasに、データ、分析、AIのための統合され、スケーラブルなアーキテクチャを提供しました。今ではデータサイエンティストは、レガシーなSnowflakeプラットフォームと比較して、**開発の生産性を40%向上**させることで、顧客セグメンテーションモデルやfuzzyマッチングアルゴリズムやソーシャルネットワーク分析に対する予測的分析のプロトタイピングによる新たなイノベーションを行なっています。

ほかのお客様である、VGZはボトルネックを引き起こすレガシーなクラウドデータウェアハウスを有しており、製品のタイムラインを遅延させコストを上昇させていました。チーム間でのリソース共有は非効率性を引き起こしただけではなく、時代遅れのガバナンスフレームワークはセキュリティを複雑なものにしていました。これらの制限はデータドリブンのランドスケープにおいての効果的なイノベーションやスケーリングを困難なものにしていました。Databricks SQLは[VGZにおけるデータアクセスとレポーティングを円滑にし](https://www.databricks.com/customers/vgz)、チームは迅速に洞察を提供し、顧客のニーズにより応えられるようになりました。統合されたプラットフォームを持つことで、ボトルネックを排除し、コラボレーションを改善し、より迅速でデータドリブンな意思決定を直接サポートすることで、新たなデータ製品における**市場投入のスピードを30%改善**しました。
