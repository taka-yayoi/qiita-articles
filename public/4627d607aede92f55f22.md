# Databricks SQL

あなたがSQLクエリーやBIツールを主に取り扱っているデータアナリストなのであれば、[Databricks SQL](https://docs.databricks.com/sql/index.html)を用いることで、お使いのデータレイクに格納されているデータに対して、アドホックなクエリーを実行したりダッシュボードを作成するための直感的な環境を手に入れることができます。Databricks Data Science & EngineeringやDatabricks Machine Learning環境でのノートブックの開発にフォーカスしている本書をスキップし、以下の資料を参照いただくこともできます。

- [データアナリストとしてDatabricksを使い始める](https://qiita.com/taka_yayoi/items/8cda2e2c85ca0ed45286)
- [Queries in Databricks SQL](https://docs.databricks.com/sql/user/queries/index.html)
- [SQL reference](https://docs.databricks.com/sql/language-manual/index.html)
