# Databricks AI Dev Kit とは

AIコーディングアシスタントからDatabricksを直接操作できる [Databricks AI Dev Kit](https://github.com/databricks-solutions/ai-dev-kit) を試してみました。自然言語でSQL Warehouseの確認からダッシュボード作成まで一気通貫でできたので、セットアップ手順と動作確認の様子を紹介します。

Databricks AI Dev Kitは、Claude CodeやCursorなどのAIコーディングアシスタントからDatabricksプラットフォームを操作するためのツールキットです。MCP(Model Context Protocol)を活用して、AIアシスタントとDatabricksワークスペースの橋渡しをします。キャッチフレーズは「Vibecoding with Native Services」で、バイブコーディングでDatabricksのネイティブサービスを扱えるようにすることが目的です。

https://github.com/databricks-solutions/ai-dev-kit

主要コンポーネントは以下の3つです。

![](https://github.com/databricks-solutions/ai-dev-kit/raw/main/databricks-tools-core/docs/architecture.svg)

**Skills** — AIアシスタントにDatabricksのベストプラクティスやパターンを教えるマークダウンベースのナレッジベース。SDP/DLT、Asset Bundles、Python SDK、MLflow評価、Databricks Apps、Agent Bricksなど幅広いトピックをカバーしています。

**MCP Server** — FastMCPベースのサーバーで、SQL実行、ジョブ管理、パイプライン操作、AI/BIダッシュボード作成などの機能をMCPツールとしてAIアシスタントに公開します。

**Core Library** — フレームワーク非依存のPythonライブラリで、Databricksの高レベル関数を提供します。MCPサーバー経由でも、LangChainやOpenAI Agents SDKなど任意のフレームワークと直接組み合わせても使えます。

# セットアップ

## ワンライナーインストール

プロジェクトディレクトリを作成し、そこでインストーラーを実行します。

```bash
mkdir my-databricks-project
cd my-databricks-project
bash <(curl -sL https://raw.githubusercontent.com/databricks-solutions/ai-dev-kit/main/install.sh)
```

インストーラーが起動すると、インタラクティブなウィザードが表示されます。

## インストーラーの流れ

インストーラーは以下を対話的に設定していきます。

1. **ツール選択** — ローカルにインストール済みのAIコーディングアシスタント(Claude Code、Cursor、GitHub Copilot、OpenAI Codex)を自動検出し、チェックボックスUIで選択
2. **Databricksプロファイル選択** — `~/.databrickscfg` から既存プロファイルを読み取り、ラジオボタンUIで選択
3. **MCPサーバーのインストール先** — デフォルトは `~/.ai-dev-kit`。リポジトリのcloneとPython仮想環境がここに作られる(全プロジェクト共有)
4. **確認と実行** — サマリーを表示して確認後、MCPサーバーセットアップ、スキルインストール、MCP設定ファイル生成を実行
5. **認証** — プロファイルにトークンがなければ `databricks auth login`(OAuth)の実行を提案

:::note warn
**注意**: このスクリプトはbashで書かれているため、Windowsではネイティブ実行できません。WSL上で実行してください。
:::

## 何がインストールされるか

インストール後のプロジェクトディレクトリには以下が生成されます。

```
my-databricks-project/
├── .claude/skills/          # Databricks & MLflow スキル群
│   ├── agent-bricks/
│   ├── aibi-dashboards/
│   ├── asset-bundles/
│   ├── spark-declarative-pipelines/
│   ├── mlflow-onboarding/
│   └── ... (計23スキル)
└── .mcp.json                # Claude Code 用 MCP 設定
```

MCPサーバー本体は `~/.ai-dev-kit/` にインストールされ、全プロジェクトで共有されます。各プロジェクトの `.mcp.json` からそのパスを参照する設計です。

# 動作確認

セットアップが完了したら、プロジェクトディレクトリで `claude` を起動します。以下のスクリーンショットではVSCode + Claude拡張を使っています。

```bash
claude
```

`/mcp` コマンドでMCP接続を確認できます。

# まとめ

Databricks AI Dev Kitを使うことで、Claude Codeから自然言語でDatabricksワークスペースを操作できるようになります。セットアップはワンライナーのインストーラーで完結し、SQL実行、Unity Catalog探索、AI/BIダッシュボード作成といった操作が対話的に行えます。

スキルも同時にインストールされるため、SDP/DLTパイプラインの作成やAsset Bundlesのデプロイなど、Databricksのベストプラクティスに沿ったコード生成も期待できます。バイブコーディングでDatabricksを扱いたい方はぜひ試してみてください。
