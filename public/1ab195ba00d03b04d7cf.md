[Delta Live Tables](https://www.databricks.com/jp/product/delta-live-tables)パイプラインも一緒に管理できます。

https://docs.databricks.com/ja/delta-live-tables/tutorial-bundles.html

[バンドルの作成](https://qiita.com/taka_yayoi/items/dc7645611551177a72c6#%E3%83%90%E3%83%B3%E3%83%89%E3%83%AB%E3%81%AE%E4%BD%9C%E6%88%90)までは一緒です。

作成時に

- Include a stub (sample) notebook in 'dlt_project/src': **no**
- Include a stub (sample) Delta Live Tables pipeline in 'dlt_project/src': **yes**
- Include a stub (sample) Python package in 'dlt_project/src': **no**

と選びます。プロジェクト名は`dlt_project`としています。

# アセットバンドルのデプロイ

```sh
cd dlt_project 
databricks bundle deploy -t dev --profile <プロファイル名>
```

ワークスペースにリソースが配備されます。

# パイプラインの実行

DLTパイプラインを実行します。

```sh
databricks bundle run -t dev dlt_project_pipeline --profile <プロファイル名>
```

パイプラインが起動しました！
