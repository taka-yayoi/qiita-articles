# はじめに

2026年11月27日(金)に、ザ・プリンス パークタワー東京で Databricks Data + AI World Tour Tokyo が開催されました。

- [Data + AI World Tour Tokyo](https://dataaisummit.databricks.com/flow/db/wt26nrt/reg/page/landing)

今年は満員御礼での開催でした。私は展示エリアにある Databricks ブースのデモと説明資料を監修し、当日は一日ブースに立っていました。夜にはユーザー会 JEDAI の Meetup & クイズ大会も開催しました。

ブースにいると、セッションの様子をほとんど見られません。そこで、当日 X に投稿された #daiwt_tokyo の投稿や、ハッシュタグなしで Databricks に触れた投稿を読みながら、会場で何が話題になっていたのかを振り返ります。

展示エリアには、Databricks のブースとして次の4つを出しました。

# X で見えた参加者の声

ここからは、X の投稿から、参加者の反応が多かった話題を紹介します。

## Genie は今年も好評だった

Genie ブースは、ブースに立っていたメンバーが「大好評」と投稿するほどにぎわいました。

https://x.com/book_o_bitch/status/2126217481698337135

参加者の方からも、Genie をもっと鍛えて使い込みたいという声がありました。自然言語でデータに質問する体験は、デモで一度見ると使いどころがイメージしやすいようです。

https://x.com/soonraah/status/2126150097058832480

Genie の新しい機能を、ほかの製品の似た機能と比べて理解しようとする投稿もありました。

https://x.com/reireireijinjin/status/2126155494905741819

## Lakebase と LTAP の組み合わせが伝わり始めた

Lakebase と SQL ウェアハウスの速度を比べるアプリが分かりやすかった、という感想をいただきました。

https://x.com/reonah6/status/2126175257929355420

AI と Lakebase (LTAP) の組み合わせの良さが分かってきたという声もありました。トランザクション処理と分析を一つの基盤で扱う話は、説明だけだと抽象的になりがちです。実際に動くものと合わせて見ていただけたのが良かったのだと思います。

https://x.com/soonraah/status/2126211751754842492

## Lakehouse//RT への期待

Lakehouse//RT が一般提供になったら、Free Edition でも少しの時間だけでも試せるようにしてほしい、という要望をいただきました。ブースで話を聞いて、自分の手で試したくなった方が多かったのだと受け止めています。

https://x.com/reonah6/status/2126239351684440215

# JEDAI Meetup & クイズ大会

全セッションが終わったあとは懇親会です。懇親会の中で、18:20から JEDAI の Meetup & クイズ大会を開催しました。

- 2026年の JEDAI の活動報告
- コミュニティで活躍されたユーザーの皆様のご紹介
- JEDAI オリジナルグッズなどが当たる Databricks クイズ大会

講演者や協賛社の方々も参加される懇親会なので、講演では聞けなかったことを直接聞ける場になりました。ご参加いただいた皆様、ありがとうございました。

JEDAI のメンバーが増えていることに触れた投稿もありました。

https://x.com/yoshimura_datam/status/2126277276346327320

JEDAI は12月にもイベントを予定しています。

- 12/10(木) DatabricksではじめてのAIエージェントもくもく会 (オンライン)
- 12/16 JEDAI 2026 忘年会 Meetup

申し込みは connpass から受け付けています。

# まとめ

X の投稿を読みながら、Data + AI World Tour Tokyo 2026 を振り返りました。

- 今年も満員御礼で、**キーノートはサテライト会場を開放するほどの盛況だった**
- ブースは Genie、Lakebase、Lakehouse / Unity Catalog、AI & Agents の4つ
- **Genie は今年も好評で、実際に使い込みたいという声が多かった**
- Lakebase と LTAP は、AI との組み合わせの良さが伝わり始めた
- Lakehouse//RT を Free Edition でも試したいという要望をいただいた
- 夜は JEDAI Meetup & クイズ大会を開催した

一番の収穫は、ブースで直接お話しした方の反応と、X に流れてくる感想の両方から、何が刺さったのかを確かめられたことでした。ブースに立っているとセッションはほとんど見られませんが、X の投稿をたどると会場全体の空気がよく分かります。投稿してくださった皆様、ご来場いただいた皆様、ありがとうございました。
