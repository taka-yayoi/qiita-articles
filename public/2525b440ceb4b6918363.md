`0.3.9-rc.1`をインストールします。

```py
%pip install -U openai mlflow
%pip install langchain-openai>=0.3.9-rc.1
%restart_python
```

MLflowトレースも有効化します。

```py
import mlflow
mlflow.langchain.autolog()
```

```py
import os
os.environ["OPENAI_API_KEY"] = dbutils.secrets.get(scope="demo-token-takaaki.yayoi", key="openai_api_key")
```

```py
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(model="gpt-4o-mini")

tool = {"type": "web_search_preview"}
llm_with_tools = llm.bind_tools([tool])

response = llm_with_tools.invoke("今日のポジティブなニュースストーリーはなんですか？")
response
```
