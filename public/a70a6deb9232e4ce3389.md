Gemini CLI連携を試してみます。

```sh
npm install -g @google/gemini-cli@nightly
```

環境設定を行います。上のタブで表示されている情報を設定します。

```sh
mkdir .gemini
vi ~/.gemini/.env
```

```:~/.gemini/.env
GEMINI_MODEL=databricks-gemini-3-pro
GOOGLE_GEMINI_BASE_URL=https://xxxx.cloud.databricks.com/serving-endpoints/gemini
GEMINI_API_KEY_AUTH_MECHANISM="bearer"
GEMINI_API_KEY=<パーソナルアクセストークン>
```

```sh
cd /Users/takaaki.yayoi/Workspace/gemini\ sample
gemini
```

**Use Gemini API Key**を選択します。
