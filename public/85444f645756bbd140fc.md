# Databricks SearchがAI生成メタデータを活用

検索機能の対象には、Unity Catalogで管理されるテーブルにおいて生成AIが作り出すテーブルやコメントのカラムも含まれています。

# 新機能のウォークスルー

検索を行うとページ全体に結果が表示され、クイックにフィルタリングすることができます。

## URLの活用

検索パラメータはURLに含まれるので、ブックマークしておくことで簡単に検索結果にアクセスできます。

```
xxxx.databricks.com/search?q=covid_cases+type%3Amarketplace&o=xxxxxx
```

# その他の機能

- **最近のアセット**: 検索バーをクリックした際に、過去に参照したアセットがドロップダウンに表示されます。
![Screenshot 2024-03-05 at 19.56.02.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1168882/c2aa31de-a7b5-cd24-a193-4f8e882dfdca.png)
- **キーボードショートカット**: “CMD+P” (Mac) / “CTRL+P” (Windows)で検索バーに移動できます。
- **新規タブで検索ページをオープン**: 検索でEnterを押すのではなく、“CMD+Enter” (Mac) / “CTRL+Enter” (Windows)を押すと、検索結果が新規タブで開きます。
- **空の検索条件で検索**: 特定のフィルター条件で全てのオブジェクトを表示したい場合には、検索条件を入力しないで検索を行います。
![Screenshot 2024-03-05 at 19.58.55.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1168882/1e291b63-dbc3-99cb-5b38-4887d3420640.png)
- **コードの検索**: ノートブックやクエリーを名称だけでなくコンテンツで検索できます。
![Screenshot 2024-03-05 at 20.01.26.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1168882/0900cdc8-8501-fe18-09a0-b29bd49b22b6.png)
