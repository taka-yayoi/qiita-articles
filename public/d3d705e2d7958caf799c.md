意外にハマったのでメモ。

**やりたいこと**

> m秒を含むUnixタイムスタンプをSparkで読み込んで、Sparkのtimestamp型に変換したい

簡単だろうと思ったら一筋縄では行きませんでした。そもそも、Unixタイムスタンプにm秒ありとなしがあることも知りませんでした。

こちらが参考になりました。

https://lara-bell.com/2017/12/trap-of-unix-timestamp/

- m秒なし: 10桁
- m秒あり: 13桁

m秒なしなら[`from_unixtime`](https://spark.apache.org/docs/3.1.3/api/python/reference/api/pyspark.sql.functions.from_unixtime.html)を呼び出すだけです。しかし、説明にあるように対応しているのは秒までです。なので、以下のようにして変換するのですが、当然m秒は落ちてしまいます。

```py
df = df.withColumn(
    "spark_timestamp", F.from_unixtime(df.unix_timestamp / 1000).cast("timestamp")
)  # unix timestamp から spark timestamp へ (m秒が丸められている)
```

色々探していたら、こちらを見つけました。

https://stackoverflow.com/questions/61246054/convert-unix-timestamp-into-ms-timestamp-in-pyspark

> デフォルトの`to_timestamp`, `from_unixtime`, `unix_timestamp`関数はm秒を返しません。
>
> しかし、ワークアラウンドとしてm秒のタイムスタンプを得るために、`from_unixtime`と`concat`関数を使います。

なんと。試します。

```py
import pyspark.sql.functions as F

df = spark.createDataFrame([
    {'unix_timestamp': 1723191602124},
    {'unix_timestamp': 1723192950521}
])
display(df)
```
![Screenshot 2024-08-09 at 17.57.49.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1168882/6a359892-f4dd-965e-9319-24ba35b6f25e.png)

はじめに上述の手法を試します。

```py
df = df.withColumn(
    "spark_timestamp", F.from_unixtime(df.unix_timestamp / 1000).cast("timestamp")
)  # unix timestamp から spark timestamp へ (m秒が丸められている)
display(df)
```

秒までしか入っていません。
![Screenshot 2024-08-09 at 17.58.34.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1168882/0bbe55bc-43cb-01b1-d8f5-33b734a58cba.png)

ワークアラウンドを試します。わかりにくいですが、以下の流れです

1. 秒までのタイムスタンプを日付表現に変換
1. m秒を表現する文字列を抽出
1. `concat_ws`を用いて`.`を区切り文字として上の二つを文字列結合
1. `yyyy-MM-dd HH:mm:ss.SSS` 形式の文字列から Spark timestamp に変換

```py
df = df.withColumn(
    "spark_timestamp_w_milli",
    F.concat_ws(  # (3) 秒までの文字列とm秒の文字列をカンマ区切りで結合 
        ".",
        F.from_unixtime(
            F.substring(F.col("unix_timestamp"), 0, 10), "yyyy-MM-dd HH:mm:ss"
        ),  # (1) タイムスタンプの最初の10文字からyyyy-MM-dd HH:mm:ssに変換
        F.substring(F.col("unix_timestamp"), 11, 3),  # (2) m秒を表現する11文字目から3文字を取得
    ).cast("timestamp") # (4) yyyy-MM-dd HH:mm:ss.SSS 形式の文字列から spark timestamp に変換
)  

display(df)
```

できました！
